# 二次开发接口

主应用默认地址：`http://127.0.0.1:4319`。

## 工作流

- `POST /api/workflow/jobs`
- `GET /api/workflow/jobs/latest`
- `GET /api/workflow/jobs/:jobId`
- `GET /api/workflow/jobs/:jobId/text`
- `POST /api/workflow/runs/:runId/resume`
- `POST /api/workflow/runs/:runId/rerun`

工作流结束只生成草稿交接清单，不会自动开始平台处理。

## 七平台草稿

- `GET /api/draft-publisher/status`
- `GET /api/draft-publisher/runs/latest`
- `GET /api/draft-publisher/runs/:runId/payload`
- `GET /api/draft-publisher/runs/:runId/assets/video`
- `GET /api/draft-publisher/runs/:runId/assets/audio`
- `GET /api/draft-publisher/runs/:runId/assets/cover4x3`
- `GET /api/draft-publisher/runs/:runId/assets/cover16x9`
- `POST /api/draft-publisher/jobs`
- `GET /api/draft-publisher/jobs/:jobId`
- `POST /api/draft-publisher/platforms/:platform/open-login`

创建草稿任务的请求体：

```json
{
  "runId": "2026-07-25-1784973485335",
  "platforms": ["douyin", "bilibili", "ximalaya"]
}
```

服务器会从该次运行的清单解析真实素材。禁止恢复 `/api/publish` 或任何正式提交接口。
