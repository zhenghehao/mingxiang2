# 草稿发布扩展

这个目录用于承载“冥想一键工作流”的草稿发布能力，与现有生成流水线和
`~/Desktop/最终发布` 正式发布服务隔离。

## 安全边界

- 默认只创建本地待发布任务。
- 平台明确提供“保存草稿”时，才允许点击对应草稿按钮。
- 找不到草稿按钮或无法确认保存成功时立即停止。
- 不调用“立即投稿”“确认发布”“提交”“发表”等正式发布动作。
- 不使用规避平台检测的参数或反复自动重试。
- 所有平台最终由用户人工检查和发布。

## 计划接入

- 视频：抖音、快手、小红书、视频号、哔哩哔哩。
- 音频：喜马拉雅、网易云音乐播客。
- 上游输入：工作流生成的 MP4、MP3、封面、标题、简介、标签及发布清单。

## 与现有项目的关系

- 主工作流：`/Users/shareit/Desktop/冥想一键工作流`
- 现有正式发布器：`/Users/shareit/Desktop/最终发布`
- 草稿版原型：`/Users/shareit/Desktop/vibe coding/social-auto-upload-draft`

后续草稿适配器、任务队列、接口和测试都放在本目录中。除非单独确认，不修改
现有正式发布器，也不让主工作流自动调用正式发布接口。
