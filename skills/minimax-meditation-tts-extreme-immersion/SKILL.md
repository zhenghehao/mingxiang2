# MiniMax 极限滞后助眠配音

把现有冥想文稿加工成 MiniMax `text` 字段可直接合成的中文纯文本。保持主题、结构和安全意图，不处理背景音乐、音色克隆或文件上传。不预设成品时长。

## 节奏规则

1. 按完整意群切分长句。在每个中文逗号、分号、冒号、问号、感叹号和句号后插入一个合法 `<#x#>`，让声音形成明显滞后。
2. 使用以下停顿范围：
   - 句内意群、口语微顿：`1.5–2.5` 秒；
   - 普通完整句、安抚描述、场景铺陈：`3.5–5.0` 秒；
   - “没关系”“不需要”“允许自己”等卸防句：`5.0–7.0` 秒；
   - 主动呼吸、环境音接管、意识游离：`7.0–10.0` 秒；
   - 夜间结尾逐级拉长，但最终一句末尾不放停顿标记。
3. 对“一进，一出”“一层，一层”等对称意群使用相等停顿。对海浪、水波、雨声、泉水等自然周期使用较长留白。
4. 在画面转换、卸下重担、身体被承托、念头远去和声音退场处使用长留白；不要为固定时长填充内容。
5. 保持中午或晚上的结尾属性：中午保留完整唤醒，晚上禁止加入唤醒。

## 用户指定时长

- 用户未指定时长时，不预设成品长度，按内容自然结束。
- 用户明确指定极限滞后版 10 分钟或 20 分钟时，先读取 [时长校准](references/duration-calibration.md)，按真实样片标尺控制原稿中文字数。
- 把字数范围当作结构预算，不要直接截断旧稿；在范围内写出完整开场、发展和自然结尾。
- 音色、语速、停顿规则或片头片尾长度改变后，不要继续套用旧标尺，应重新用成品节点校准。

## 呼吸与动作文字

- 把 `(inhale)`、`(exhale)`、`(breath)`、`(sigh)`、`(sighs)`、`(humming)` 等英文动作标签改成听众应直接听见的自然中文。
- 使用“现在，轻轻吸气。<#7.0#>再缓缓呼气。<#8.0#>让肩膀一点点松开。”一类完整中文引导。
- 禁止输出 `呼——吸——`、`吸——呼——` 等机械拟声。

## 强制约束

- 每个内部中文标点后必须有且只有一个 `<#x#>`；最终一句末尾允许不放标记，避免尾部标记后没有可发音文字。
- 禁止连续放置两个停顿标记。
- 每个停顿标记前后都必须有可发音的中文内容。
- `<#x#>` 的 x 范围为 `0.01–99.99`，最多两位小数。
- 只输出 TTS 纯文本，不输出标题、解释、舞台说明、参数、JSON、curl、Markdown 代码围栏或预计时长。
- 单次同步文本必须少于 10000 字。

## 输出前检查

1. 扫描并清除全部英文括号动作标签和机械呼吸拟声。
2. 检查内部中文标点后的停顿标记没有漏标。
3. 检查不存在连续标记、首部标记或尾部悬空标记。
4. 检查长停顿集中在完整句、呼吸、画面转换和意识退场处，句内停顿保持在较低档。
5. 检查中午稿有唤醒结尾，晚上稿没有唤醒结尾。
