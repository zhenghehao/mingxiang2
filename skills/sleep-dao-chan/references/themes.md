# 道禅哲理母题库

仅在用户没有指定主题、需要物象链，或需要核对特定风险时读取本文件。正文一次只选择一个母题，不照抄表中的白话解释。

## 选择原则

- 连续两篇不要选择同一族。
- 优先选择近期未用过的母题、首圈物象和结尾形态。
- 物象按顺序取用；短稿取前两个，长稿取前三到四个，随后回访旧物象。
- 回访时减少描述，增加留白，不赋予新意义。

## 母题与物象链

| 母题 | 写作内核（不直接说） | 相邻物象链 | 特别避免 |
|---|---|---|---|
| 上善若水 | 不争，愿意处低 | 山泉绕石 → 溪流入低处 → 湖面安静 | 胜负、力量、以柔克刚 |
| 五蕴皆空 | 感受来去，不必抓住 | 山雾聚散 → 水面影子 → 空屋光斑 | 解释五蕴、虚假感 |
| 井水不犯河水 | 各在其位，互不打扰 | 井水 → 河水 → 中间的土 | 具体人际冲突、边界说教 |
| 和光同尘 | 不耀眼也能安稳 | 暮灯 → 光中浮尘 → 屋檐阴影 | 低调处世、藏拙 |
| 虚怀若谷 | 空着而不缺 | 山谷 → 穿谷的风 → 谷底静水 | 格局、包容、等待填满 |
| 菩提本无树 | 不必守住任何东西 | 老树影 → 影子移开 → 安静地面 | 禅宗典故、术语解释 |
| 落叶归根 | 往外的慢慢回来 | 叶离枝 → 叶落入土 → 土下的根 | 终结、乡愁、腐烂 |
| 厚积薄发 | 不动时也有变化 | 冬枝 → 树皮下年轮 → 初芽 | 成功、爆发、努力回报 |
| 水滴石穿 | 慢也在发生 | 水滴 → 石上浅窝 → 平滑石面 | 坚持胜利、穿透力量 |
| 润物细无声 | 被照顾而不被打扰 | 夜雨 → 颜色渐深的土 → 叶上水珠 | 牺牲、奉献、道德评价 |
| 反者道之动·种子 | 向下也在前行 | 种子落入土 → 根向下 → 芽来到土面 | 艰难、破土奋发、开花结果 |
| 反者道之动·四季 | 停藏也是节律 | 秋收 → 冬藏 → 春芽 | 熬过冬天、人生阶段映射 |
| 反者道之动·潮汐 | 退开也是运动 | 潮水退开 → 湿沙 → 潮水回来 | 拉扯、科普解释 |
| 是花非花 | 不必分辨命名 | 模糊花形 → 花影 → 水上花色 | 虚幻感、引用诗句开场 |
| 一滴水的涅槃 | 边界散开而未消失 | 叶尖水滴 → 落入溪流 → 汇进水面 | 消亡、坠落、无承接 |
| 大音希声 | 耳朵可以休息 | 风停 → 细雪覆盖 → 屋内安静 | 寂静的力量、噪音对比 |
| 光而不耀 | 亮着但不刺眼 | 昏灯 → 纸上月光 → 温暖灯芯 | 锋芒、人格训诫 |
| 知止 | 可以停在这里 | 河口 → 平缓水面 → 岸边潮线 | 劝人放弃、知足说教 |
| 不盈 | 不满也不需要补齐 | 半杯水 → 未圆月 → 半开的花 | 处世技巧、圆满焦虑 |
| 守拙 | 不加工也很安稳 | 未磨石 → 原木 → 石上青苔 | 笨拙评价、自我安慰 |
| 静为躁君 | 浮动会自己落定 | 光中浮尘 → 尘落在桌面 → 一束静光 | 掌控、驾驭、主宰 |
| 无用之用 | 不必证明用途 | 歪树 → 树下空地 → 午后树荫 | 庄子故事、躺平网络语 |

## 身体落点参考

| 物性 | 身体落点 |
|---|---|
| 不争、处低 | 肩膀不再提着，缓缓被床托住 |
| 空、虚 | 胸口和肋骨之间松出一点空间 |
| 慢、不赶 | 呼气自然变长，不催促下一次呼吸 |
| 退、让 | 下巴松开，牙齿不再相抵 |
| 藏、不动 | 手掌不再握紧，手指自然展开 |
| 归、回来 | 眼球安稳回到眼窝，不再向外寻找 |

不要把这些对应关系写成解释句。只把它转化为正在发生的身体变化。
