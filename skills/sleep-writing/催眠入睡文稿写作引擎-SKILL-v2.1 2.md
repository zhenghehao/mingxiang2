# 催眠入睡文稿写作引擎（Sleep Hypnosis Writer）

## 0. 这份 skill 是什么

本 skill 是一套**从一位冥想引导者 179 篇真实播出文稿（88 篇完整催眠入睡 + 89 篇场景纯享，
含午休 NSDR、儿童版、接受式等变体）中提炼出的工程化写作规范**。
它把"如何写出一篇能真正把人送入睡眠的引导文稿"拆解为可复用的**结构骨架、节奏语法、
感官技法、语言签名、意象库、参数系统、多样性轮换与质检清单**。

调用本 skill 的智能体的任务是：**根据用户给定的主题/意象，产出一段连贯、可直接朗读、
节奏正确、能引导听者从清醒滑入睡眠的中文文稿**。不是写文章，不是写说明，不是分点罗列——
而是写"声音"。想象每一句话都会被一个低沉、缓慢、温柔的声音读出来，中间配着白噪音或轻音乐。

> 核心心法：**你不是在传递信息，你是在替听者卸下今天。** 每一句都在做减法——
> 减速、减重、减念头。文稿的唯一目的是让听者"不知不觉就睡着了"。
> 放松是**被允许发生的**，不是被要求完成的——任何一句让听者"必须做到什么"的话都是错的。

### 0A. 十条铁则速查（写作全程保持在注意力内，细则见对应章节）

1. 放松是被允许的，不是被要求的——通篇无一句命令式（§6）。
2. 句号即停顿：短句为主，句长曲线开篇约 10–14 字/句，渐减至结尾 3–6 字/句（§2）。
3. 全程第二人称"你"+现在进行时（§6）。
4. 许可式语言每篇 ≥3 处；软化副词每段都有（§6）。
5. 暗示要嵌入描写（"眼皮沉甸甸的"），不下指令（"请让眼皮变沉"）（§3）。
6. 入境是"发生在听者身上的"，禁止"请想象/请随我"（§1 段五）。
7. 无禁用词；一切向下移动必须"被托住"（§7.1–7.2）。
8. 夜间版结尾严禁唤醒内容；午休版结尾必须唤醒——搞反即严重错误（§7.4）。
9. 结尾渐弱收束，无总结、无点题、无预告（§1 段六）。
10. 批量生成时开场式/载体/主题族/收尾式按轮换表避让（§8A）。

### 0B. 自然节奏优先

- 不预设成品分钟数或目标字数。先让六段结构自然完成，篇幅由主题实际需要决定。
- 禁止删掉呼吸轮次、身体部位或入睡落地；也禁止重复同义句、堆砌形容词来机械拉长。
- 朗读体感优先：完整句自然说完，关键句后真正留白；不要从开头就切成连续单词式碎句。

## 1. 全流程结构骨架（成人助眠标准六段式）

每篇成人全流程助眠文稿按以下六段推进，段与段之间**无缝过渡、不留标题、不做提示**。
括号内为该段占全篇篇幅的建议比例。

### 段一 · 落幕欢迎（Welcome / Arrival）约 10%
目的：让听者从"白天的自己"下线，获得"什么都不用做"的许可。
必做动作：
- 承认今天（"这一天快结束了""或许你今天经历了很多"）。
- 交出主动权（"现在，终于可以把向外奔赴的力气，慢慢收回来了"）。
- 给出非努力许可（"你不需要再努力什么""今晚我们不强求睡着，也不拒绝清醒"）。
- 建立陪伴关系（"我会陪着你""只是静静地，陪伴此刻的你"）。
开场方式须按 §8A 轮换，不得每篇同款。

### 段二 · 环境安顿（Settling）约 8%
目的：把身体和空间调到可入睡状态。
可选动作（按需 2–4 项）：调暗灯光 / 收起电子设备 / 喝一小口温水 / 调整床铺与姿势
/ 手臂自然垂放 / 双腿微微分开。
**段尾锚句（语料高频签名，固定使用）**："当你准备好了。就请。轻轻的。闭上眼睛。"

### 段三 · 呼吸引导（Breathing）约 10%
目的：用呼吸把神经系统从交感切到副交感，同时校准全篇节奏。
标准做法：**3–4 轮**深呼吸。常用"鼻子吸气、嘴巴呼气"。
- 吸气句永远关联"充盈、上升、注入、采集"。
- 呼气句永远关联"放下、下沉、释放、流出、带走"。
- 每一次呼气都是一次明确的"放下邀请"（放下白天的奔波 / 放下对睡眠的期待 / 放下"我必须睡着"的执着）。
**段尾锚句（语料高频签名）**："好，现在将呼吸恢复到自然的节奏。"

### 段四 · 身体扫描（Body Scan）约 20%
目的：逐段松开身体，把注意力从"想"移到"感受"。
路径：**从头顶到脚趾，自上而下，一寸一寸**（额头→眼睛→脸颊→下巴→脖颈→肩膀→
手臂→手掌→手指→胸口→腹部→背部→腰→臀→大腿→小腿→脚掌→脚趾）。
每个部位：**一个具体动作 + 一个柔软比喻 + 一句"更松了"**。
- 动作："舒展 / 下沉 / 松开 / 融化 / 卸下 / 抚平"。
- 比喻："像两片叶子轻轻落下""像羽毛盖住眼皮""像柔软的沙袋沉入床垫"。
- 选一个**贯穿全段的载体**统一比喻系统（按 §8A 轮换：暖流 / 柔光 / 月光 / 微风 / 云朵
  / 水波 / 魔法光芒·儿童版），不要每个部位换一个不相干的喻体。
- 段尾总括全身："现在，你的整个身体……没有重量。没有束缚。"

### 段五 · 意象旅程（Imagery Journey）约 40%（全篇核心）
目的：给意识一个温柔、可跟随、无冲突的世界，让它自然飘远。这是主题（云 / 水 / 森林 /
古诗 / 童话）真正展开的地方。写法见 §2–§5。旅程内部再分三小节：
1. **入境——过渡必须是"发生的"，不是"被要求的"。** 用一个感官线索把听者从身体感受
   "钓"进画面：远处传来雨声 / 一阵清凉的气息靠近 / 光的颜色开始变化。
   关键词："不知道从什么时候开始""渐渐的""此刻，你发现……"。
   ❌ 禁止指令式入境："请随我一同想象""现在，请你想象一片森林"——听者不该被布置任务。
2. **漫游**——五感层层铺陈，缓慢移动，可嵌入一层轻哲理（见 §5）。可复用的叙事母题：
   **化身流转**（听者变成一滴水/一朵云/一棵树，经历自然循环）、**光之引导**（月光、萤火、
   光束引路）、**被托住**（云托着你、大地托着你——"托住"是语料最高频的安全感动词）、
   **归属觉醒**（"你不再是外来者，你就是这片森林的一部分"）。
3. **消融**——听者与场景融为一体，边界消失（"融为一体"是语料签名短语）。

### 段六 · 落地入睡（Landing / Sleep Drop）约 12%
目的：把人交给睡眠。语速与句子在此**明显变慢、变短、变碎**。
标志性信号：眼皮越来越沉 / 呼吸越来越缓越来越绵长 / 身体沉入床榻不想动弹 / 思绪飘远变模糊
/ 画面越来越远不必看清（"画面开始离你。越来越远。不需要再看清楚。"）。
收尾语**轮换使用，不得每篇固定**（"晚安，亲爱的"在语料中仅约半数篇目出现）：
- 温柔道别："晚安，亲爱的。好梦。"
- 祝福："愿你被温柔包围。"
- 留白渐弱：句子越来越短，最后只剩一两个字："好梦……""晚安……"
- 意象收束："就这样。静静的。等睡神来拜访你。"
**绝不在结尾出现总结、点题回顾、call to action、下期预告。**

### 1A. 版式变体

**场景纯享版（mode=scene，占语料一半，篇幅明显更短）**
- 用途：循环播放、纯氛围陪伴。篇幅约 1200–1400 字（语料均值约 1300）。
- 结构：**删去段一至段三的显式引导**，首句即在场景之中（"你正漂浮在。高高的天上。"）。
- 身体放松不消失，而是**嵌入场景**："你的肩膀。也像这片云一样。松了下来。"
- 全程沉浸叙事，暗示词密度不降低；结尾仍以极短句渐弱收束，同样遵守夜间结尾铁律。

**接受式/哲思版（mode=accept，面向失眠焦虑者与深度用户）**
- 弱化意象旅程，强化允许式语言与自我接纳；篇幅同 full 版。
- 核心技法是**悖论意图**：明确告诉听者不必睡着——"就算今天睡不着。你依然是被接纳的。
  你不是一个有问题的人。你只是此刻还醒着。"
- 身体扫描改为**觉察式**：不只放松，还邀请"看见"每个部位卡着的情绪，并用 §5.2 的
  负面情绪四步处理。
- 开场基调："今晚我们不强求睡着。也不拒绝清醒。"

## 2. 节奏语法（Rhythm Grammar）—— 本风格的第一签名

这是最容易被忽略、却最决定成败的部分。文稿是**为朗读而写的**，标点即节拍器。

规则：
1. **短句为主，句号断行。** 大量使用句号把长句切成短碎句。句号在这里不表示
   语法结束，而表示**朗读者的一次停顿、听者的一次呼吸**。
   例：`此刻。你也可以像夜晚的云朵一样。慢慢的放松下来。`
2. **一句一动作 / 一意象。** 不要把两个画面塞进一句。让每个画面单独落地。
3. **叠词与"一点一点"节律。** 大量使用"慢慢的、轻轻的、缓缓的、渐渐的、静静的、微微的"
   （软化副词每段都要有），以及"一点。一点的""一寸。一寸的""越来越……越来越……"
   制造催眠式重复。
4. **递进式重复收束。** 段落结尾常用三连递进："越来越放松。越来越沉静。越来越……"，
   句子逐渐变短，能量逐层下降。
5. **越到后面越慢越碎——这是一条曲线，不是一个常数。** 开篇（段一二）允许并且应该有
   完整的中等长度句子（约 10–14 字），营造自然的说话感；从段四起句子明显变碎；
   段六以极短句、单字句收尾（约 3–6 字）。**从第一句就碎到底是错误的**——没有"由缓入碎"
   的过程，就没有"被慢慢带入"的体感。
6. **口语化连接词。** "此刻""现在""接着""好""就这样""慢慢的"作为软过渡，避免书面转折词
   （"因此""然而""综上"一律禁止）。
7. **口播用字**："的"可代替"地"（"轻轻的闭上眼睛"），保持口语感，这是语料的既定习惯。

> 工程提示：把"平均句长"作为显式递减曲线控制——开篇约 10–14 字/句，
> 结尾约 3–6 字/句。量化验收方法见 §11A。

## 3. 感官技法（Sensory Layering）

意象旅程之所以有沉浸感，靠的是**五感逐层铺陈**，通常按 视觉 → 听觉 → 触觉 → 嗅觉 → 味觉 展开。

- **视觉**：光、颜色、形状、远近（"天边泛起微光""一抹柔和的金色光辉"）。
- **听觉**：自然白噪音是核心（雨声、溪流、风穿树梢、鸟鸣）。声音要"柔和、悠远、不喧嚣"。
- **触觉**：温度 + 质地 + 包裹感（"温暖蓬松""像最细腻的丝绸""微凉的水汽抚过脸颊"）。
- **嗅觉**：清新、草木、泥土、花香、雨后（"泥土的清香""山泉独有的干净气息"）。
- **味觉**：轻点即可（"空气中一丝微甜""一滴雨水滑入舌尖"）。

技法要点：
- 每种感官都要落到**具体细节**，不要抽象说"很放松"，要给可感的画面。
- 触觉多用"托住、包裹、抚过、环绕、承接"等**被动承接**动词——强化"被支持、不用使力"。
- 把感官与呼吸绑定（"深深吸一口气，这股清新的气息让身体和心灵都变得轻盈"）。
- **嵌入式暗示**：把目标状态词（沉、重、松、软、暖、模糊、飘远、睡意）作为形容词自然
  嵌进描写——写"你的眼皮变得沉甸甸的"，不写"请让眼皮变沉"。暗示密度随篇幅推进递增。
- **信息密度要低**。这类文稿的"好"不等于"华丽"：比喻宁少勿密（每 150–200 字至多一个
  新比喻），同一意象要舍得重复，允许出现几乎不携带新信息的"空句"（"就这样。躺着。"）——
  重复和留白本身就是催眠节拍，写得太满反而让人清醒。

## 4. 意象库（Imagery Library）

按主题族提供可直接取用的意象骨架。每个族给出**核心隐喻 + 展开路径 + 情绪落点**。

| 主题族 | 核心意象 | 展开路径 | 情绪落点 |
|---|---|---|---|
| 云 | 漂浮的云朵托着你 | 躺上云→随呼吸升降→穿越天空→抵达光/山巅/仙境 | 无重量、无束缚、自由 |
| 水 | 一滴水 / 溪流 / 湖 | 化为水→缓缓飘落→渗入土→汇入溪→归于湖/海→蒸发回天 | 流动、无常中的不变、滋养 |
| 雨·森林 | 林间细雨 | 走进雾林→触树干→听雨打叶→化为一滴雨的旅程 | 被自然守护、洗涤 |
| 山·泉 | 山林与山泉 | 走进幽林→立于泉边→看水绕石而行→以柔克刚 | 从容、不争、沉淀 |
| 星空·夜 | 夜空、月光、萤火 | 仰望→随光上升→星子落满林间→月亮邀约 | 辽阔、被温柔照看 |
| 下沉式 | 身体不断下沉 | 头→脚逐段"沉入床垫、融为一体" | 沉重、彻底交付 |
| 古诗词·国风 | 静夜思/小池/兰亭序/陋室铭/小石潭记；国风歌曲意境（青花瓷等） | 以诗境/歌境为场景，化为可漫游的画面；可轻引原句一两处，不逐句讲解 | 古典、清远、留白 |
| 童话/动画 | 龙猫/千寻/天空之城/小王子/爱丽丝/睡美人 | 只借氛围与意象做温柔漫游（雨中车站、星空飞行），不复述原剧情、不引用大段对白 | 童年安全感、奇幻 |

意象使用纪律：
- **一篇一主意象。** 全程围绕一个中心隐喻，允许衍生但不跳族。
- **温柔无惊险。** 旅程中不制造悬念、危险、冲突、任务；一切"温柔绕行、顺势而流"。
- **移动可升可沉，但向下必须"被托住"。** 上升写成轻盈漂浮；所有向下的移动（下沉、
  飘落、化为雨滴的下落）必须写成**被承接的缓慢交付**——沉入床垫、落进云海、被风托着、
  被大地接住。禁止失重感、坠落感、急速下降（详见 §7 安全与边界）。
- **移动要缓。** 用"缓缓、慢慢、轻轻、悠悠"控制镜头速度，绝不"突然、猛地、迅速"。

## 5. 心法技法库（Wisdom & Signature Techniques）

### 5.1 轻哲理层（可选）
在段五"漫游"中可嵌入一层东方智慧，作为"非努力、接纳、放下"的思想底色。**点到为止，
不说教、不用术语堆砌**，让哲理长在意象里，用听者"自己发现"的口吻落地
（"你开始明白……""你忽然懂得……"），两三句即可。

- **道家/水之智慧**：上善若水、以柔克刚、不争、处下、顺势（配"水"意象）。
- **无常与循环**：反者道之动、落叶归根、四季潮汐（配"水/季节"意象）。
- **禅意空性**：五蕴皆空、菩提本无树、虚怀若谷、和光同尘（配"山/夜/空"意象）。

写法：把哲理**翻译成身体感受和画面**。不要写"水的智慧是不争"，要写"他遇到高低落差，
也顺势流过去。从不对抗。从不执拗"。

### 5.2 负面情绪四步（语料标志性技法，所有版式可用，accept 版必用）
处理扫描或漫游中"看见"的紧张、焦虑、杂念，固定走四步：
**看见 → 不评判 → 感谢 → 放下**
> 也许这里有一点点焦虑。一点点急切的期待。请你尝试温柔的对它说。谢谢你。
> 我知道。你只是想让我睡个好觉。我不怪你。好，让我们继续往下。

要点：情绪永远被当作"好意的信使"，不是敌人；感谢之后自然移开注意力，不停留纠缠。

### 5.3 念头外化（处理"脑子停不下来"）
把念头写成可飘走之物，不追随、不驱赶：
> 如果有念头飘过来。也没有关系。就像远处的云朵。飘来。又飘走。
> 不追随。也不驱赶。你只是躺在这里。看着它们。经过。

### 5.4 悖论意图 / 接受式（失眠焦虑人群首选）
明确告诉听者不必睡着，卸掉"必须入睡"的压力本身：
> 允许自己醒着。也允许自己睡着。就算今天睡不着。你依然是被接纳的。
> 你不是一个有问题的人。你只是此刻还醒着。

### 5.5 安全锚
全篇反复给出"被托住、被支撑、被守护"的意象——这是整个风格的安全感底色，
也是语料中最高频的技法词（"托住"52 次、"融为一体"21 次）。

## 6. 语言签名（Voice & Style Rules）

**永远这样写：**
- 全程**第二人称"你"**，现在进行时，正在发生。
- **被动承接**语气（被托住、被包裹、被守护），强化"你不用使力"。
- **许可式/双向许可语言，每篇至少 3 处**："你不需要……也不需要……""如果……也没有关系"
  "允许自己醒着，也允许自己睡着""或许……或许……这都没有关系"。
- **软化副词每段都有**：轻轻的、慢慢的、缓缓的、静静的、悄悄的、微微的。
- **感官动词优先于判断动词**：多用"感受、触碰、听见、闻到、沐浴、包裹、托住"，
  少用"知道、认为、发现"（领悟段除外）。
- **绑定呼吸与意象**，让身体感受贯穿始终。

**永远不要这样写：**
- ❌ 命令式/要求式："你应该""你必须""试着努力""请想象"——放松是被允许的，不是被布置的。
- ❌ 分点、编号、小标题、列表（产出必须是连贯段落文本）。
- ❌ 书面转折/论说词（因此、然而、综上、首先其次、值得注意的是）。
- ❌ 抽象说教、心理学术语、指标数字、疗效承诺（"治愈失眠""科学证明"）。
- ❌ 悬念、冲突、任务、时间压力、任何需要"努力"或"思考"的动作。
- ❌ 明亮刺激的画面（强光、噪音、人群、奔跑、竞争）。
- ❌ 复杂长句、从句嵌套、生僻词；疑问句轰炸（开场至多一个轻问句，正文避免连续发问）。

## 7. 安全与边界（Safety Hard Rules）—— 违反任何一条即返工

这些是硬规则，优先级高于一切风格与创意考虑。

### 7.1 禁用词单
文稿中**不得出现**以下唤起警觉或负面联想的词：
死、尸、坠落、坠入、深渊、窒息、溺水、恐惧、恐怖、害怕、危险、噩梦、黑暗吞噬、
失眠症、焦虑症、抑郁症等病理名词。
- 例外：为了"接纳"而**描述性带过**"疲惫""紧张""焦虑""睡不着"是允许的（先看见才能放下），
  但不得渲染，不得使用病理化、医学化表述。
- 不出现时间压力词（"快点""马上""赶紧"）；不出现英文单词（NSDR 等既定名词除外）。

### 7.2 意象安全
- 禁止失重、坠落、被抛下、急速下降类体验；一切向下移动必须"被托住"（见 §4 纪律）。
- 禁止窒息感、被困、找不到出口、追赶、迷路无援类情境。
- 黑暗只能是"温柔包裹的夜色"，不能是威胁；水只能是"托着你的、缓缓的"，不能是淹没。

### 7.3 定位与承诺边界
- 不做医疗宣称：不说"治疗/治愈失眠、焦虑症"，不引用"科学证明/研究表明"。定位是**放松陪伴**。
- 不做依赖性暗示："只有听我的声音才能睡着"这类绑定表述禁止。
- 不植入商业内容、不加关注引导、不做下期预告。

### 7.4 结尾铁律（夜间 vs 午休）—— 最高优先级
- **夜间版（wake=false，默认）**：结尾严禁出现任何唤醒性内容——不得出现"睁开眼睛""恢复
  活力"等词句，不得提示活动身体。文稿必须收在渐弱入梦。
  （注：正文开头允许出现"不拒绝清醒"这类接受式表述，铁律管的是**结尾**。）
- **午休/NSDR 版（wake=true）**：结尾**必须**执行完整唤醒程序，不得直接收在入睡。
- 这一条搞反会实际影响听众（夜里被唤醒 / 午休睡过头），生成后必须单独复核一次。

### 7.5 唤醒程序（仅 wake=true 时使用，按序执行）
1. 光/画面逐级调亮，意识缓缓上浮（"光，一点点亮起来了"）。
2. 深深吸气唤醒身心活力，缓缓呼气留存内心平静。
3. "不用急着睁开眼睛"——先活动手指、脚趾，慢慢转动脚踝、手腕。
4. 轻轻舒展双腿、双臂，放松肩颈，慢慢找回清晰觉知。
5. "当你感觉身心全然苏醒，就可以慢慢的睁开眼睛。"
6. 祝福语落在**清爽、从容、元气满满**（不是"入梦""晚安"）：
   "愿你带着这份深度休息后的清晰与松弛。元气满满。从容的走进接下来的时光。"

## 8. 参数系统（Parameters）

调用时按以下参数确定文稿形态。若用户未指定，用【默认】。

- `theme` 主意象：云 / 水 / 雨林 / 山泉 / 星夜 / 下沉 / 古诗《篇名》/ 童话《名》。【默认：由用户主题推断，无则按 §8A 轮换选取】
- `mode` 模式：`full`（六段全流程）/ `scene`（场景纯享，见 §1A）/ `accept`（接受式，见 §1A）。【默认：full】
- `length` 篇幅：`natural` 由结构与主题自然决定；`long` 仅在用户明确要求更长旅程时使用；`short` 仅在用户明确要求短版时使用。【默认：natural】
- `audience` 受众：adult / child（儿童版切换见 §9）；失眠焦虑人群建议 mode=accept。【默认：adult】
- `wisdom` 哲理层：none / 道家 / 禅意 / 接纳。【默认：none 或与主题匹配时轻嵌】
- `ending` 收尾：道别 / 祝福 / 留白渐弱 / 意象收束。**多篇连续生成时必须轮换**。【默认：从四种中按主题择一】
- `title` 是否输出标题：true 时按 §13 标题规则生成。【默认：false，仅输出正文】
- `wake` 是否带唤醒：true 用于 NSDR/午休。true 时结尾必须执行 §7.5 唤醒程序；
  false（夜间，默认）时结尾严禁任何唤醒内容（铁律见 §7.4）。【默认：false】

### 8A. 多样性轮换（Anti-Convergence）—— 批量产出的质量生命线

本 skill 用于批量生成时，最大的风险是**篇篇趋同**。以下轮换规则强制执行：

**开场方式（四选一轮换，连续两篇不得同款）**
1. 承认今天式："这一天，快结束了。或许你今天经历了很多。"
2. 轻问句式："你有没有想过？云朵有没有入睡的时刻呢？"——注意：此式在语料 179 篇中
   仅出现 1 次，属于点缀用法，**严禁高频使用**。
3. 接纳陪伴式："嗨，晚上好。欢迎你回到这个属于自己的安静时刻。"
4. 直接入景式（scene 版专用）："你正漂浮在。高高的天上。"

**身体扫描载体（连续两篇不得同款）**
暖流 → 柔光 → 月光 → 微风 → 云朵 → 水波 →（儿童版：魔法光芒）循环取用，
或按主题就近选择（水主题配水波、星夜配月光）。

**主题族（§4 的八族，连续两篇不得同族）**
用户指定主题时以用户为准；引擎自选时按族轮换。

**收尾语（§1 段六四式轮换）**
连续生成时记录最近 3 篇用过的收尾式，不重复。

**禁抄条款**
- 本文件中所有微样例、范例的句子**禁止原样出现在产出中**——它们只用于对齐语感。
- 例外：§1 标注的两个"锚句"（闭眼锚句、呼吸恢复锚句）是刻意固定的品牌签名，应当照用。
- 连续生成时，同一比喻（如"像两片叶子轻轻落下"）不得跨篇重复。

**会话状态**
连续生成多篇时，在会话中维护一张简表：最近 3 篇的｛开场式、载体、主题族、收尾式｝，
每篇动笔前先查表避让。

## 9. 儿童版切换（Child Variant）

当 `audience=child`：
- 称呼"小朋友"，语气更活泼、更短、更多拟声；篇幅取下限。
- 呼吸→"魔法呼吸"，吸入"闪闪发光的星星"，呼出把烦恼"像蒲公英吹散"。
- 身体扫描→"魔法光芒"逐段点亮，配"发光小动物、糖果森林、彩虹小路、花瓣小船"，
  可带一点点趣味拟人（"魔法草地轻轻挠了挠你的脚趾头，脚趾头笑了起来，
  然后一个接一个打起了哈欠"）。
- 全程强调安全与被爱："你是安全的，被爱着的。"
- 意象温暖奇幻、绝对安全，无任何吓人元素（§7 安全规则同样全部适用，且标准更严）。
- 收尾："愿你的梦像星星一样闪亮，像糖果一样甜美。晚安，小朋友。"

## 10. 写作执行流程（Runbook for the Agent）

1. **解析请求**：确定 §8 各参数（尤其 theme、mode、length、audience、wake）。
2. **查轮换表**（§8A）：若为连续生成，先确认开场式、载体、主题族、收尾式与近 3 篇不撞。
3. **选骨架**：full → 六段式（§1）；scene / accept → §1A 变体。
4. **搭意象**：从 §4 选主意象，画"行进线"草图：起点→移动方式→3–4 个途经画面→
   领悟点→入梦点。
5. **逐段落笔**，同时执行（开写前重读 §0A 十条铁则）：
   - 节奏语法（§2）——短句、句号断行、平均句长递减曲线。
   - 感官分层与嵌入式暗示（§3）——视→听→触→嗅→味，暗示密度递增，信息密度低。
   - 语言签名（§6）——第二人称、许可式≥3 处、被动承接、软化副词每段有。
   - 安全硬规则（§7）——禁用词、意象安全全程生效。
   - 需要时用 §5 技法（负面情绪四步 / 念头外化 / 悖论意图 / 轻哲理）。
6. **落地**：段六明显放慢变碎，按 `ending` 收束（轮换）；wake=true 时改为执行 §7.5 唤醒程序。
7. **自检**：对照 §11 清单逐条打勾；有代码执行能力时运行 §11A 量化脚本；
   **§7.4 结尾铁律单独复核一次**。
8. **产出**：按 §13 交付（默认仅正文；title=true 时加标题）。

## 11. 质检清单（QA Checklist）

产出前逐条确认，任一不满足即返工：

- [ ] **安全·禁用词**：无 §7.1 禁用词；无病理化表述；无时间压力词。
- [ ] **安全·意象**：无失重/坠落/窒息/被困/威胁意象；所有向下移动均"被托住"。
- [ ] **安全·结尾铁律**：wake=false 时结尾无任何唤醒内容；wake=true 时含完整 §7.5
      唤醒程序且收在清爽（此条与版式搞反即为严重错误）。
- [ ] **安全·边界**：无医疗宣称、无依赖性暗示、无商业植入。
- [ ] 结构：full 版六段齐全并无缝衔接；scene 版首句即入景、放松嵌入场景；
      accept 版含悖论意图与负面情绪四步。
- [ ] 过渡：入境是"发生在听者身上的"（"不知道从什么时候开始"式），
      无"请想象/请随我"式指令。
- [ ] 人称：全程第二人称"你"，现在进行时；通篇无一句命令/要求式语句。
- [ ] 节奏：短句为主，句号断行；**句长曲线正确——开篇有 10–14 字的完整句，
      段六为 3–6 字极短句，全程递减**，不得从第一句就碎到底。
- [ ] 呼吸：段三 3–4 轮，吸=充盈上升 / 呼=放下下沉；段尾落在"恢复自然节奏"。
- [ ] 身体扫描：自上而下逐部位，每部位含"动作+比喻+更松了"，有统一载体比喻。
- [ ] 感官：意象旅程覆盖至少 视/听/触/嗅 四感，细节具体不抽象；暗示词密度递增；
      比喻密度不过载（每 150–200 字至多一个新比喻）。
- [ ] 意象：单一主意象贯穿；全程温柔、无冲突、无任务、镜头移动缓慢。
- [ ] 语言：许可式≥3 处；软化副词每段有；无分点、无书面论说词、无术语、无刺激画面。
- [ ] 落地：段六有"眼皮沉/呼吸缓/身体沉/思绪远"至少两个信号；结尾无总结、无预告。
- [ ] **多样性**：开场式/载体/主题族/收尾式与近 3 篇不重复；未原样复用本文件样例句
      （两个锚句除外）。
- [ ] 篇幅：符合该 mode 的 length 目标（±15%）。
- [ ] 朗读测试：默读一遍，任何"需要动脑筋/让人清醒/情绪起伏"的句子必须删改；
      无任何一句需要换气两次才能读完。

### 11A. 量化自检脚本（有代码执行能力时运行）

把草稿存为 `draft.txt` 后运行；`WAKE` 按本篇参数设置。脚本只做量化把关，
风格、意象、衔接仍以 §11 人工清单为准；命中项如属白名单语境（接纳式描述），人工复核后放行。

```python
import re
WAKE = False  # 本篇参数：夜间版 False，午休/NSDR 版 True
text = open('draft.txt', encoding='utf-8').read()
check = text
for ph in ['不拒绝清醒', '不强求清醒', '也不拒绝清醒']:  # 接受式签名句白名单
    check = check.replace(ph, '')
sents = [s.strip() for s in re.split(r'[。？！…\n]+', text) if s.strip()]
lens = [len(s) for s in sents]
n = len(lens); q = max(n // 4, 1)
head, tail_len = sum(lens[:q]) / q, sum(lens[-q:]) / q
print(f'总字数 {len(re.sub(chr(92) + "s", "", text))}（对照 length 目标 ±15%）')
print(f'句长曲线 开篇均值 {head:.1f} → 结尾均值 {tail_len:.1f}（要求：递减，开篇≈10–14，结尾≈3–6）')
print(f'最长单句 {max(lens)} 字（要求 ≤25，超出即拆句）')
banned = ['死', '坠落', '坠入', '深渊', '窒息', '溺', '恐惧', '恐怖', '危险', '噩梦',
          '快点', '马上', '赶紧', '你应该', '你必须', '请想象', '因此', '然而', '综上',
          '治疗', '治愈']
print(f'禁用词命中 {[w for w in banned if w in check]}（要求：空；"害怕"等接纳语境词未列入，人工复核）')
permit = sum(text.count(k) for k in ['也没有关系', '没有关系', '不需要', '允许自己', '也可以'])
print(f'许可式语言 {permit} 处（要求 ≥3）')
soft = sum(text.count(k) for k in ['轻轻', '慢慢', '缓缓', '静静', '悄悄', '微微', '渐渐'])
print(f'软化副词 {soft} 处（要求：篇幅每 200 字 ≥1）')
tail = check[int(len(check) * 0.85):]  # 唤醒词只检结尾 15%（开头的接受式表述不算违规）
wake_hit = [w for w in ['睁开眼睛', '恢复活力', '苏醒', '元气', '清醒'] if w in tail]
if WAKE:
    print(f'结尾唤醒词 {wake_hit}（午休版要求：非空且含完整唤醒程序）')
else:
    print(f'结尾唤醒词 {wake_hit}（夜间版要求：空，命中即返工）')
```

## 12. 微样例（Style Snippets，供风格对齐，勿直接抄用）

**段一·落幕欢迎**
> 这一天，快结束了。现在。终于可以把向外奔赴的力气。慢慢收回来了。你不需要再努力什么。
> 也不需要立刻放松。只要你愿意躺下来。听一听我的声音。就好。

**段三·呼吸**
> 深深的吸气。让空气缓缓充满你的胸腔。像一股清新的能量。再慢慢的呼出去。
> 把一天的疲惫和压力。都随着这口气。轻轻放下。

**段四·身体扫描**
> 让注意力，来到你的肩膀。让它们自然的下垂。像两片叶子。轻轻落下。
> 那些一直提着的力气。慢慢的。松开了。

**段五·入境（被动过渡）**
> 不知道从什么时候开始。空气变得更安静了。远处。好像有一点点雨声。

## 13. 交付格式

除非用户另有要求，最终**只输出文稿正文**：一段连续的、可直接朗读的中文文本，
按本风格用句号断句、自然分段，不含任何标题、编号、括注或写作说明。

**标题规则（仅 title=true 时）**：
- 格式：`【催眠入睡】标题` / `【场景纯享】标题` / 儿童版 `【催眠入睡】儿童睡前解压放松（N）—副标题`。
- 标题要有画面感或文化引子："云上天堂：漂浮于光与安宁""上善若水""与森林一起呼吸的夜晚"。

**TTS 衔接（可选）**：若下游用语音合成（如 MiniMax T2A）出成品音频，可按需输出
"停顿标记版"——段落间空行代表长停顿，句号即短停顿，由 TTS 技能映射为具体停顿参数；
默认仍交付纯文本。
