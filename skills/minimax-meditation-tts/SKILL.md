# MiniMax 冥想配音文本优化

把现有冥想文稿加工成 MiniMax `text` 字段可以直接合成的纯文本。不改变主题与安全意图，但必须修正赶读、机械碎句、命令式表达、重复赘述和口语不顺。不处理音乐、音色克隆或文件上传。

## 自然节奏原则

- 不追求固定分钟数。最终时长由自然语速、内容完整度和语义留白决定。
- 停顿服务于呼吸和画面，不用于机械凑时长；同样不得因为想缩短时长而删掉必要留白。
- 保留完整意群，避免把每个词切碎。开场像自然说话，身体扫描逐渐放慢，入睡结尾才明显变短、变轻、变疏。
- 对 800 字以上的夜间文稿，明确停顿总量通常应达到正文字符数的 `0.07–0.11 秒/字`；这是质检范围，不是要求逐句平均分配。

## 处理流程

1. 保持原稿的开场、呼吸放松、身体扫描或想象旅程、深化、结尾结构。
2. 把过长句拆成适合缓慢朗读的完整意群，修正明显口语不顺；禁止从第一句开始就切成连续单词式碎句。
3. 在句间加入合法 `<#x#>` 停顿：
   - 普通完整意群：`1.0–1.6` 秒；
   - 许可、安抚与身体部位转换：`1.5–2.2` 秒；
   - 画面或段落转换：`2.5–4.0` 秒；
   - 环境声接管、入睡深化与结尾：`3.0–5.0` 秒；
   - 引导吸气或呼气后的留白：`4.5–6.5` 秒。
4. 呼吸引导只能写听众应该直接听见的中文，例如：
   - `现在，轻轻吸气。<#4.0#>感受胸口慢慢舒展。`
   - `再缓缓呼气。<#5.0#>让肩膀一点点松开。`
5. 保持中午或晚上的结尾要求：中午保留完整唤醒，晚上禁止加入唤醒。
6. 把 `呼——吸——`、`吸——呼——` 等容易被机械朗读的拟声写法改成完整中文引导。

## 强制约束

- 禁止输出 `(inhale)`、`(exhale)`、`(breath)`、`(sigh)`、`(sighs)`、`(humming)` 等英文括号动作标签。它们可能被自定义音色当作正文读出。
- 将上述含义改为自然中文：`轻轻吸气`、`缓缓呼气`、`自然换气`、`轻轻叹一口气`、`轻声哼唱`。
- 禁止输出 `呼——吸——`、`吸——呼——` 等机械拟声；必须改成自然句子与合法长停顿。
- `<#x#>` 的 x 范围为 `0.01–99.99`，最多两位小数。
- 每个停顿标记前后都必须有可发音文字；禁止连续放置两个停顿标记。
- 不输出舞台说明、参数解释、标题、JSON、curl、Markdown 代码围栏或预计时长。
- 单次同步文本必须少于 10000 字。

## 输出格式

严格只输出加工完成的 TTS 纯文本，保留自然段。输出前执行以下检查：

1. 不区分大小写搜索 `\((inhale|exhale|breath|sighs?|humming)\)`，命中后全部改成自然中文。
2. 检查不存在连续 `<#x#>`。
3. 检查每个 `<#x#>` 前后都有可朗读内容。
4. 检查中午稿有唤醒结尾、晚上稿没有唤醒结尾。
5. 统计所有 `<#x#>` 的秒数；800 字以上夜间稿若低于 `0.07 秒/字`，重新分配停顿后再输出。
6. 检查停顿位于语义边界，不能为了达到秒数把一句完整的话切得支离破碎。
