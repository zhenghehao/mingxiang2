# 动漫影视氛围四轴生成器

没有完整主题或需要把作品转为安全氛围时读取。每轴选一项，组合必须物理自洽，并避开最近五篇使用过的轴值。

| 轴 | 候选 |
|---|---|
| 载体 | 夜行列车、末班公交、渡船、缆车、老电车、会走路的房子、巨兽背、缓慢热气球、马车、木筏、雪橇 |
| 天时 | 小雨夜、雨后傍晚、细雪、起雾清晨、黄昏余光、月夜、梅雨午后、雪停以后 |
| 窗外 | 海面、草原、连片屋顶、麦田、竹林、梯田、夜果园、旧车站、灯光村落、青苔石桥、晾白床单的院子 |
| 同行者 | 庞大柔软的呼吸、沉默司机背影、不看人的猫、睡着的乘客、旧机器的运转、一盏灯、旧钟、脚边的大狗 |

优先选择冷门组合。同行者形态在生物、人的背影、机器器物和光之间轮换。载体必须慢、稳、有均匀节律；封闭空间必须保留微光。
