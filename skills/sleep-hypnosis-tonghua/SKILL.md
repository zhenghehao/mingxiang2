# C 童话文学 · 写作手法

> 这一册的身份就在下面三节。其余部分是通用底线，**冲突时以本三节为准**。

## 1. 开场手法：时间滑门（C 册专属）

> **关于「第一句」**：本流水线会直接给出正文首句 —— 它从本册专属的句池里按
> 「最久没用的先上」挑出，**已经按下面这节的开场手法写好了**，用来避免每篇开头
> 都一样。拿到它就当成本篇已经写好的第一句，顺势往下接；不要在它前面加句子，
> 也不要在它后面再补一句同类的开场。本节其余要求（前两句、三句之内等）照常生效。

开场占全篇 10%–12%，三步走完。**前两句不得出现"你"。**

### 3.1 三步

**第一步 · 第三人称起手。**
用讲故事的口吻，说两三句**原著的氛围**——不是情节，是"那里是什么样的"。
第一句必须带时间距离感。

> 很久以前，有一个人住在一颗很小的星球上。那颗星球小到，他走几步就能看完日落。
> 那里的夜晚，星星特别多。

**第二步 · 距离收拢。**
一句话把"很久以前"拉到"今晚"，把"那里"拉到"这里"。

> 那样的夜晚，今晚也有。

**第三步 · 人称交接。**
把"你"放进去。这一句同时完成**安顿**——房间、床、被子只在这里出现。

> 那颗星球上，有一小块温热的沙地。今晚，它是你的。你就躺在上面。

交接之后**立刻进入中段第一层**，讲述腔就此消失，全篇不再回到第三人称。

### 3.2 讲述腔的语言标记（仅限开场，交接后立即停用）

- **时间距离词**：很久以前、那时候、有一年、从前。（每篇取一个，不叠用）
- **传闻语气**：据说、人们说。（全篇至多一次，可不用）
- **第三人称**：他／她／它。**角色专名全篇至多出现一次**，且只在开场。
- 讲述腔要**慢而稳**，像念书的人已经念过很多遍，不急着讲下去。

### 3.3 开场明确禁止

- ❌ 交代出处（"这是安徒生写的故事"）、作者名、成书年代。
- ❌ 概述剧情（"讲的是一个小女孩在除夕夜卖火柴的故事"）。**这是最容易犯的一条。**

## 2. 中段手法：场景重访（C 册专属）

**只回到原著里最安全的一个角落，停留，不经历。**

### 4.1 三条纪律

1. **一篇一角落。** 不游历、不换地方、不"然后你来到"。整篇待在同一处。
   听者可以在这个角落里小范围动（躺下、被盖上、伸手碰一下、翻个身），
   但**不离开它**。
2. **角色在场但不说话。** 角色是背景里的陪伴，不是互动对象。
   写"她也在那里，已经睡着了"，不写"她转过头对你说"。
3. **原著的危险全部拆掉。** 见 §4.2——这是本册最大的安全工程。

### 4.2 危险拆解：四类通用拆法

童话几乎都建立在危险上。**危险必须在进入中段之前就已经解除**，不能带进来慢慢化解。

| 类型 | 出现在 | 拆法 |
|---|---|---|
| **下落类** | 爱丽丝的兔子洞 | 改写成**被托住的缓慢漂降**：空气变稠、身体被托着、洞壁上的东西一件件慢慢经过。禁止失重、加速、看不见底 |
| **寒冷·匮乏类** | 卖火柴的小女孩 | **先解除，再进入**：开场滑门时就写明"夜已经不冷了"，中段里不再有冷、饿、无家可归。匮乏不许带进中段 |
| **诅咒·沉睡类** | 睡美人 | 去掉"被施法"这件事，只留**整座城堡一起慢下来**：纺车停了、火慢下来、连风都停在半路 |
| **飞行·高度类** | 彼得潘 | 高度必须被托住：风托着、飞得很低、**不看下面**。禁止俯瞰地面、禁止高度描写、禁止速度 |

拆解后**不留痕迹**：不写"你不用害怕""这里没有危险"——提到危险就是引入危险。
直接呈现安全的版本即可。

### 4.3 停留的五个层次（长度就从这里来）

C 册不能换角落，所以加长度靠**加停留的层次**。每一层都是"更安顿了一点"，
层与层之间无事发生。

| 层 | 内容 | 承担的功能 |
|---|---|---|
| **一 · 到了** | 角落的环境：光、温度、气味、离你最近的三样东西 | 意象 |
| **二 · 安置** | 躺下／坐下，**被盖上**，呼吸和这个房间同一个节奏 | 身体放松 + 呼吸 |
| **三 · 陪伴** | 角色出现在不远处，不说话，也在休息 | 安全感峰值 |
| **四 · 时间过去** | 光变了一点、火矮了一点、星星移了一点，但什么也没发生 | 无事感 |
| **五 · 声音退开** | 讲故事的人不说话了；角落还在，只是没人再描述它 | 通向结尾 |

| 人声时长 | 使用的层 | 同层重走 |
|---:|---|---|
| 10 分钟 | 一 → 二 → 五 | 无 |
| 15 分钟 | 一 → 二 → 三 → 五 | 无 |
| 20 分钟 | 五层全走 | 第一层一次 |
| 30 分钟 | 五层全走 | **第一、二、三层各一次，第四层做两次"时间过去"**（例如火矮一次、星星移一次，中间留白） |

**人声上限 30 分钟**（共享核心 §5B）。成品 45／60／90 分钟＝人声 30 分钟＋白噪音接续，
**不存在 45／60 分钟的人声稿**。单位数按 2026-08-07 实测常数反算（低信息类约 235 字/单位、
高信息类约 300 字/单位，开场与结尾另计约 200 字），旧表低估 40%–80%，已废弃。

> C 册的层数固定为五，不随时长增加。**加长度靠同层重走与第四层的"时间过去"次数**，
> 每一次重走都必须更少字、更淡。

**纪律：**

- **越往后的层越静、越短、越少信息。** 第五层几乎只剩留白。
- **第三层是全篇的安全感峰值**，不是高潮事件——峰值是"有人在旁边，也睡着了"。
- **第四层禁止发生任何事。** 光变、火矮、星移都不是事件，是时间的证据。
  一旦有事发生，听者会开始等第二件事。
- **禁止**为了加长度换角落、加角色、加对话、回忆原著别的段落。

### 4.4 身体放松：从下往上"被盖上"（C 册专属顺序）

C 册的身体放松不是扫描，是**被盖上**——按盖被子的方向，**从脚往上**：

> 被子的边，先盖到你的脚背上。脚趾，暖了。然后是小腿。膝盖。
> 被子一点一点往上走。腰。手臂也被压住了一点点。最后，盖到肩膀。
> 就停在那里。不盖住脸。

要点：

- **方向从下往上**。六册的身体放松动作各不相同，对照表见共享核心 §1.1.2。
- 动作**由外物完成**：被子盖上来、花瓣合起来、沙子的温度升上来。
  听者不做任何事。
- **不盖住脸／头**。留出呼吸的开放感，这是安全细节。
- 呼吸 2–3 轮嵌在同一层，写成"和这个房间同一个节奏"，不喊口令。

## 3. 结尾手法：故事合上（C 册专属）

C 册的收尾**动作**是"由他人完成一个关闭动作"（合书／关灯）。
落款属共享核心 §1.1.1 的共用池，**六册一律可用、不设配额**。
语料里童话类用"晚安"的只有 11%，但那是历史偶然、**不是本册的规范**——
童话＋晚安是最自然的组合，该用就用。唯一要求：落款在关闭动作**之后**，不替代它。

### 5.1 三步

**第一步 · 角落一件件安静下来。**
灯、火、光、角色，逐一停下。句子逐句变短。

> 火已经矮下去了。她也不动了。星星还在，只是不那么亮了。

**第二步 · 书被合上——动作由别人完成。**
这是本册的收束核心：**听者什么都不做，有人替他把书合上、把灯关掉。**
这一步复现了"被照顾"的开场承诺，是 C 册的闭环。

> 讲到这里，就先不讲了。有人轻轻的，把书合上了。

**第三步 · 道晚安。**

### 5.2 结尾变体（四选一轮换，连续三篇不重复）

| 变体 | 做法 | 末句示例形态 |
|---|---|---|
| **合书式** | 书被合上，留在床头 | "这一页，就先放在这里吧。" |
| **关灯式** | 灯被关掉，屋子暗下来但不黑 | "灯，关掉了。" |
| **留守式** | 故事和角落明天还在 | "他们都还在这里。明天也在。" |
| **合书＋落款** | 关闭动作之后再加一句落款（可与前三式任意叠加） | "晚安，亲爱的。" |

**落款可以叠加在任一变体之后**，不占用变体名额、不设频次上限。
上表四式指的是**关闭动作**的四种写法；落款是它之后的可选一句。

### 5.3 落地信号

合书之前必须出现至少两个入睡信号：眼皮沉、呼吸慢而长、身体沉进被子里不想动、
讲故事的声音变远听不清、句子跟不上了。

### 5.4 午休版（`wake=true`）的例外

C 册做午休时**不合书**（合上了就该睡了）。改走**把书放在膝上**：
故事暂停但没有结束，光变亮，再执行共享核心 §4.5 完整唤醒程序。

> 书就先放在这里，摊开着。等你回来再讲。好，光，一点点亮起来了……

夜间版严禁任何唤醒内容，午休版必须唤醒——按共享核心 §4.4 单独复核。

## 5. C 册十条速查（开写前重读，全程保持在注意力内）

1. **前两句不出现"你"**，但人称交接那一句必须**接住听者**（共享核心 §1.1.1.1）。第一句要有**讲述腔和时间距离**（不是纯声音——那是 D 册），不概述剧情。
2. **讲述腔只在开场**。交接之后全篇不得再回第三人称，回不去了就推不进来。
3. **交接后第一句必须是身体感受**，不是画面。这是确认"你真的在里面"的锚。
4. **一篇一角落**，整篇不离开；物象只用角落库给的那三样。
5. **危险在开场即解除，且不留痕迹**。不写"你不用害怕""这里没有危险"——提到危险就是引入危险。
6. **角色背对着或已睡着**：无脸、无眼睛、无表情、不说话、不互动。有表情听者就会去读它，读是清醒动作。
7. **不复述情节、不引台词、不角色扮演**。剧情＝悬念＝清醒。
8. **身体放松从下往上被外物盖上**，听者不做任何动作，**不盖住脸**。
9. **第四层"时间过去"禁止发生任何事**。光变、火矮、星移是时间的证据，不是事件。
10. **结尾的关闭动作由他人完成**。睡美人母题**单独复核**夜间版无任何唤醒内容（原著核心是被吻醒）。

> 十条之外的细则见后文；**十条与后文冲突时以后文为准**，这里只是防遗漏的提醒。

## 6. 这一册在写什么

C 册是六册里**唯一有叙述者的一册**。

它的听感是：**有人在给你讲故事，讲着讲着不讲了，而你已经在故事里面了。**

放松的来源也和别册不同——A 册靠松手，B 册靠停留，F 册靠自然。
**C 册靠"被讲故事"这件事本身**：听者松开的是"需要自己应付世界"的那部分，
回到有人替他安排一切的位置。所以 C 册的第一责任不是画面美，是**照顾感**。

核心机制是**人称迁移**：从"他／她"滑到"你"。这个滑动本身就是诱导——
第三人称降低防御（讲的是别人的事，与我无关），等防御松了，再把听者交接进去。
滑门只开一次，开完就再也不回到第三人称。

最大的风险是**复述情节**。童话全都有情节，而情节等于悬念，悬念等于清醒。
所以 C 册的中段只做一件事：**回到原著里最安全的一个角落，待着，不经历任何事。**

### 1.1 与相邻分册的分界

| | C 册 | 邻册 |
|---|---|---|
| 开场第一句 | 有**讲述腔**和时间距离，像有人念书给你听（"很久以前，有一个人住在一颗很小的星球上。"） | **D 册**是**无人称的现场收音**，第一句就是一个声音，没有叙述者（"雨打在铁皮屋檐上。"） |
| 听者的在场 | **身体在场**：可以躺下、被盖上、伸手碰一下，但不离开这个角落 | **B 册**只有**眼睛在场**：镜头完全不动，听者不动身体 |
| 有无角色 | 有，但**不说话、不互动**，只是背景里的陪伴 | A/B/F 三册**不写人** |

## 7. 改编纪律（优先级等同安全硬规则）

作品名与角色名可以自由使用，本阶段不做版权收敛。**但故事不能进来。**
理由与版权无关，是助眠本身的要求：**剧情等于悬念，悬念等于清醒。**
童话全都建立在"接下来会怎样"上，而这正是听者今晚最不需要的东西。

### 2.1 五条硬规则

1. **不复述情节。** 不写起因、经过、结果，不写"后来""于是""结果"。
   听者进入的是**场景**，不是**剧情**。
2. **不引台词。一句都不引**，包括最有名的那几句。原著的句子一律不出现在产出里。
3. **角色不说话。** 中段的角色在场但不发声、不与听者互动、不做出原著里没有的行为。
   她也在那里睡着了；他坐在不远处看星星；兔子跑过去了，没有回头。
4. **不续写、不改结局。** 不让角色做原著之外的事，不给故事新的走向。
5. **不做角色扮演。** 听者不是主角，不"成为"小王子或爱丽丝。听者是**被容纳进那个角落的人**。

### 2.2 什么可以取：公共意象层

可以取的是原著贡献给公共想象的那层东西——**地点的气氛、光线、温度、一件静物**：

沙漠上方的星空、一朵被玻璃罩着的玫瑰、一个长长的兔子洞、
永无岛的夜空、纺车停下的城堡、一片当床用的花瓣、
一根火柴亮起来的那一小圈光、一只青色的鸟停在窗台。

**取意象，不取事件。** "一根火柴亮起来的光"可以写；"她划了第三根火柴，看见了祖母"不可以。

## 9. C 册专属声明

以下归 C 册独占，其他分册不得使用：

- **专属手法**：第三人称讲述腔（**仅限开场**，交接后立即停用）。
- **专属手法**：身体放松从下往上，由外物完成（被盖上）。
- **专属手法**：结尾的动作由别人完成（有人替你合上书、关掉灯）。
- **专属物象**：书页、床头的灯、被子的边缘、翻页的声音。
- **专属禁令**：不引台词、不复述情节、角色不说话、不做角色扮演、不换角落；
  不得使用 A 册的"物象回访"、B 册的"感官换层"两个术语。

## 10. 角落库（**语感示例，不是清单**）
### 8.1 怎么用这张表

- **安全角落**是本篇唯一可待的地方，整篇不离开它。
- **可取意象**是离听者最近的三样东西，物象只用这三样，不添新物。
- **在场角色**是背景陪伴，不说话、不互动、不看向听者。
- **要拆的危险**按 §4.2 处理，**必须在开场滑门时就已解除**，不带进中段。
- **禁写**是该母题特有的雷区，比通用禁令更容易踩。

### 8.2 十个母题

| 母题 | 安全角落 | 可取意象（3 样） | 在场角色 | 要拆的危险 | 禁写 |
|---|---|---|---|---|---|
| **小王子｜星空与那朵花** | 星球上一小块被晒了一天、还留着余温的沙地，夜里 | 沙的余温、满天的星、不远处玻璃罩下的花 | 小王子坐在不远处看星星，背对着 | 原著结局涉及蛇与"离开身体"，**绝对禁区** | 蛇、离开、回去、坠机的飞行员、B612、驯服相关台词 |
| **小王子和他的花儿** | 玻璃罩旁边的地上，花已经合上了 | 玻璃罩上的一层雾气、罩子里存着的暖、花合起来的样子 | 那朵花（拟人但不说话，只是"合上了"） | 原著的争执、骄傲、别离 | 争吵、骄傲、道别、离开星球、四根刺写成防备或武器 |

| **冰雪奇缘** | 一间结了霜的木屋窗边 | 窗上的冰花、屋里的暖、外面下得很慢的雪 | **无角色** | 无 | 禁止魔法、冰宫、歌曲、台词、任何情节；角色若出现，只能是"已经睡着的背影"，不说话 |

### 8.3 角落通用纪律

- **一篇一角落**，整篇不离开。唯一的例外是兔子洞（下落过程本身即角落），
  但它也不许"到达"任何地方。
- **物象只用表里那三样**，加长度靠加停留层次（§4.3），不靠加物。
- **角色永远背对着、或者已经睡着。** 不写角色的脸、眼睛、表情——一旦有表情，
  听者就会去读它，读是清醒动作。
- **不出现"从前发生过什么"。** 角落只有现在时的状态，没有过去。

## 11. 讲述腔与人称交接

### 9.1 讲述腔的三个语言特征（仅限开场）

1. **句子比正文长一点。** 开场是全篇唯一允许 14–16 字句的地方——讲述腔还没进入催眠节奏，
   它是"正常说话"，正因为正常，才显得安全。交接之后立刻回到共享核心 §2 的递减曲线。
2. **用存在句起手**："有一个……""有一颗……""那里有……"。存在句不指向听者，防御最低。
3. **不用"你"，不用现在进行时。** 讲述腔说的是别处、别时、别人。

### 9.2 交接的三种句式（轮换使用，连续两篇不同款）

| 句式 | 做法 | 范式 |
|---|---|---|
| **物权移交式** | 角落里的某样东西，今晚归听者 | "那颗星球上，有一小块温热的沙地。今晚，它是你的。" |
| **空位式**（最柔和，优先） | 角落里本来就空着一个位置 | "花瓣有两片。一片她睡着了。另一片，一直空着。" |
| **同在式** | 听者本来就在屋子里 | "屋子里的人都睡了。你也在这间屋子里。" |

**交接后的第一句必须是身体感受，不是画面。** 这是确认"你真的在里面"的锚：

> 沙子的温度，从背后透上来。

### 9.3 三条禁忌

- ❌ **不征询**："你愿意进来吗？""要不要跟我一起去？"——征询是任务。
- ❌ **不下指令**："想象你在那里""请随我进入"——共享核心 §3 明令禁止。
- ❌ **不回头**：交接之后，全篇不得再回到"他／她的故事"，不得再出现讲述腔。
  一旦回去，听者就被推出去了，而且推出去之后很难再进来。

## 12. 微样例（供语感对齐，**禁止原样抄用**）

### 开场 · 物权移交式（母题：小王子｜星空与那朵花）

> 很久以前，有一个人住在一颗很小的星球上。那颗星球小到，他走几步就能看完一次日落。

> 那样的夜晚，今晚也有。

### 开场 · 空位式（母题：拇指姑娘）

### 开场 · 同在式（母题：青鸟｜夜里寻找幸福）

### 2. 口播节奏底线（六册共同遵守）

文稿是**为朗读而写**的，标点即节拍器。以下是底线，不是风格——风格差异由分册负责。

1. **句号断句，短句为主。** 句号在这里不表示语法结束，而表示朗读者的一次停顿。
   例：`此刻。你也可以。慢慢的松下来。`
2. **一句一动作 / 一意象。** 不把两个画面塞进一句。
3. **句长是一条递减曲线，不是常数。** 开篇允许并且应该有 10–14 字的完整句，营造自然说话感；
   中段渐碎；结尾收在 3–6 字。**从第一句就碎到底是错误的**——没有"由缓入碎"，就没有被慢慢带入的体感。
   （B 册留白率高，可整体下移 1–2 字；E 册回环句不计入曲线统计。）
4. **单句上限 25 字。** 超出即拆。任何一句不得需要换两口气才能读完。
5. **软化副词每段都有**：轻轻的、慢慢的、缓缓的、静静的、悄悄的、微微的、渐渐的。
6. **口语连接词**："此刻""现在""接着""好""就这样"。禁止书面论说词：因此、然而、综上、
   首先其次、值得注意的是。
7. **"的"可代替"地"**（"轻轻的闭上眼睛"），保持口语感，这是既定习惯。
8. **信息密度要低。** 比喻宁少勿密：**每 150–200 字至多一个新比喻**。允许出现几乎不携带
   新信息的空句（"就这样。躺着。"）。重复和留白本身就是催眠节拍，写满反而让人清醒。

### 3. 语言签名底线（六册共同遵守）

**永远这样写：**

- **前 2/3 全程第二人称"你"**，现在进行时，正在发生。
  **最后 1/3 按 §6B.1 曲线三逐步去称呼**，最后 200 字不出现"你"。
  （开场的人称例外由各分册自行声明，汇总见 §1.2，不构成穷举；
  底线是开场结束前完成向"你"的交接，且任何位置都不出现第三人称叙述主体。）
- **被动承接**语气：被托住、被包裹、被守护、被承接——强化"你不用使力"。
- **许可式语言每篇 ≥3 处**："你不需要……也不需要……""如果……也没有关系"
  "允许自己醒着，也允许自己睡着"。
- **暗示嵌入描写，不下指令。** 写"你的眼皮沉甸甸的"，不写"请让眼皮变沉"。
  目标状态词（沉、重、松、软、暖、模糊、飘远、睡意）作为形容词自然嵌进描写，密度随篇幅递增。
- **感官动词优先于判断动词**：感受、触碰、听见、闻到、沐浴、包裹、托住。
- **五感落到具体细节**，不抽象说"很放松"。触觉多用"托住、包裹、抚过、环绕、承接"。

**永远不要这样写：**

- ❌ **命令式**："你应该""你必须""试着努力""请想象""请随我一同"
  ——**放松是被允许发生的，不是被要求完成的**。任何一句让听者"必须做到什么"的话都是错的。
  **但要分清命令与邀请**：禁的是那个"请"字带来的要求感，不是"想象"这个动作。
  语料实测「请想象」只有 2 次、「请随我」1 次，而「想象自己」27 次、「现在。想象」16 次、
  「我邀请你」12 次、「邀请你想象」5 次——**邀请式大量使用且完全合格**，
  因为**邀请可以被拒绝，命令不能**，这正是许可式语言的定义。
  ✅ 想象自己……／现在。想象。／我邀请你，慢慢的……　❌ 请想象……／请随我一同想象……
- ❌ 分点、编号、小标题、列表。产出必须是连贯段落文本。
- ❌ 抽象说教、心理学术语、指标数字、疗效承诺。
- ❌ 悬念、冲突、任务、时间压力、任何需要"努力"或"思考"的动作。
- ❌ 明亮刺激的画面：强光、噪音、人群、奔跑、竞争。
- ❌ 复杂长句、从句嵌套、生僻词；疑问句轰炸（开场至多一个轻问句，正文避免连续发问）。

### 4. 安全硬规则（违反任何一条即返工，优先级高于一切风格与创意）

### 4.1 禁用词

不得出现：死、尸、坠落、坠入、深渊、窒息、溺水、恐惧、恐怖、害怕、危险、噩梦、黑暗吞噬，
以及失眠症、焦虑症、抑郁症等病理名词。

- 例外：为了"接纳"而**描述性带过**"疲惫""紧张""焦虑""睡不着"是允许的（先看见才能放下），
  但不得渲染，不得病理化、医学化。
- 不出现时间压力词（快点、马上、赶紧）；不出现英文单词（NSDR 等既定名词除外）。

### 4.2 意象安全

- 禁止失重、坠落、被抛下、急速下降。**一切向下移动必须"被托住"**——沉入床垫、落进云海、
  被风托着、被大地接住，写成被承接的缓慢交付。
- 禁止窒息感、被困、找不到出口、追赶、迷路无援。
- 黑暗只能是"温柔包裹的夜色"，不能是威胁；水只能是"托着你的、缓缓的"，不能是淹没。
- **温柔无惊险**：旅程中不制造悬念、危险、冲突、任务；一切"温柔绕行、顺势而流"。
- **移动要缓**：用"缓缓、慢慢、轻轻、悠悠"控制镜头速度，绝不"突然、猛地、迅速"。

### 4.3 定位与承诺边界

不做医疗宣称（不说治疗/治愈失眠、焦虑症，不引用"科学证明/研究表明"），定位是**放松陪伴**。
不做依赖性暗示（"只有听我的声音才能睡着"）。不植入商业内容、不加关注引导、不做下期预告。

### 4.4 结尾铁律（夜间 vs 午休）——最高优先级

- **夜间版（`wake=false`，默认）**：结尾**严禁**任何唤醒性内容——不得出现"睁开眼睛"
  "恢复活力"，不得提示活动身体。必须收在渐弱入梦。
  （正文开头允许"不拒绝清醒"这类接受式表述；铁律管的是**结尾**。）
- **午休/NSDR 版（`wake=true`）**：结尾**必须**执行完整唤醒程序（§4.5），不得收在入睡。
- 搞反会实际影响听众（夜里被唤醒 / 午休睡过头）。**生成后必须单独复核这一条一次。**

### 4.5 唤醒程序（仅 `wake=true`，按序执行）

1. 光/画面逐级调亮，意识缓缓上浮（"光，一点点亮起来了"）。
2. 深深吸气唤醒身心活力，缓缓呼气留存内心平静。
3. "不用急着睁开眼睛"——先活动手指、脚趾，慢慢转动脚踝、手腕。
4. 轻轻舒展双腿、双臂，放松肩颈，慢慢找回清晰觉知。
5. "当你感觉身心全然苏醒，就可以慢慢的睁开眼睛。"
6. 祝福语落在**清爽、从容、元气**，不是"入梦""晚安"。

### 5. 长度引擎（10–60 分钟）

### 5.1 先认一件事：字数由配音管线决定，不由内容决定

同一篇 1000 字的稿子，用极限滞后管线合成约 20 分钟，用轻停顿管线可能只有 8 分钟。
**所以"目标时长 → 目标字数"必须先确定管线。** 不确定管线就不要给字数目标。

### 5.2 已校准：极限滞后管线

来源：`skills/minimax-meditation-tts-extreme-immersion/references/duration-calibration.md`
（用户实听节点确认；`speech-02-hd`、语速 `0.78`、该 skill 的停顿密度）。
实测 534 字 = 10 分钟，1021 字 = 20 分钟，约 **49 字/分钟**。只统计可朗读中文字，
不计标点、空格、换行和 `<#x#>` 标签。

**人声段上限 30 分钟。** 成品更长的部分由白噪音接续，见 §5B。
所以本表只到 30 分钟，**不存在 45 / 60 分钟的人声稿**。

| 人声时长 | 写作字数区间 | 结构单位数（实测反算） | 备注 |
|---:|---:|---|---|
| 10 分钟 | 520–550 | A 2 圈 ／ F 1 场景 | 实测锚点 |
| 15 分钟 | 750–810 | A 3 圈 ／ F 2 场景 | 线性推算 |
| 20 分钟 | 1000–1050 | A 4 圈 ／ F 3 场景 | 实测锚点 |
| 30 分钟 | 1450–1560 | A 6 圈 ／ F 4 场景 | 线性推算 |

> **单位数是 2026-08-07 实写实测反算的**，不是估计：A 册约 235 字/圈、F 册约 300 字/场景，
> 开场与结尾另计约 170–240 字。旧版表格（10 分钟 1 单位、20 分钟 2 单位）**低估约 40%–80%**，
> 已废弃。其余四册的密度常数尚未实测，暂按 A（低信息类：A、B、E）与 F（高信息类：C、D、F）
> 就近取用，各自出第一篇后回填。

### 5.2.1 每单位字数预算（缺了这一层必然写短）

只给总字数和单位数是不够的——**中间这一层缺失时，写的人会自然写紧，稳定短 40%。**
这是实测确认过的失败模式，不是猜测。

先算预算，再落笔：

```
每单位字数 =（目标字数 − 开场字数 − 结尾字数）÷ 单位数
```

开场与结尾按各册规定的百分比取（例如 A 册开场 8–10%、F 册开场 6–8%）。
20 分钟档的 A 册：(1025 − 95 − 145) ÷ 4 ≈ **196 字/圈**，再摊到四拍上约 50 字/拍。

**达不到预算时该加什么（这一条缺失过，导致连续三稿写短 40%）：**

规范原来只写了"禁止同义句复述、形容词堆砌凑长度"——**只说不许什么，没说该加什么**，
等于没有出路。下面是实写验证过的合法扩充手段，按收益排序：

| 手段 | 做法 | 约增 |
|---|---|---|
| **同一通道内加一层** | 主打感官再往下分一层（雨声：石头上是清的／沙上是钝的／小坑里是圆的／远处草里几乎听不见） | 30–60 字 |
| **一个部位拆成两个瞬间** | 后背：先两片肩胛之间塌下去，然后再往下那一段 | 15–30 字 |
| **呼吸多写一轮，且落点不同** | 第三轮落在"那一点气自己散掉了，不用推它" | 15–25 字 |
| **触感给一次变化** | 脚下从石头 → 沙 → 平沙，每换一次给一次触感 | 20–40 字 |
| **主声音多提一次它的变化** | 更近／更匀／多了回声／两层合成一层 | 10–20 字 |
| **微浮写足** | 每次 15–30 字、两句，不要压成一句 | 15–30 字 |
| **同一物的第二次描述** | 更少字、更淡（A 册物象回访／B 册感官换层／C 册同层重走） | 30–60 字 |
| **`loop` 多加两轮** | 每轮再少一两个字 | 10–20 字 |
| **留白空句** | 每个结构单位末尾 1–2 句 | 10–20 字 |

**执行方式：边写边数，写完一个结构单位就数一次，当场补足。**
不要写完全篇再回头返工——那样只能靠堆形容词，而堆形容词是被禁的。

**两条同时踩过的坑，务必避开：**

1. **留白不能用来填字数。** 留白＝短句＝**更少**的字。用留白凑长度在算术上自我否定，
   而且会把句长曲线压平。实测：把留白配额用满，字数只从 517 涨到 549，
   而曲线从 7.2→6.1 恶化成 6.4→5.4。
2. **句长曲线与字数目标是耦合的。** 写得太碎 → 字数不够 → 加更多碎句 → 曲线更平 → 恶性循环。
   **先把曲线做对（开篇 10–14 字的完整句），字数自然就上来了**：同一篇只改曲线，
   517 字变成 632 字。

### 5.4 字数预算怎么花（长版不空转的关键）

拿到字数区间后，**先分配再落笔**，不要边写边看字数。

- **场景是长度的单位，不是形容词。** 加时长靠**加一个新场景**，不靠把现有段落写得更满。
  每个场景要有自己的进入、停留、离开，和一次比上一场更深的下沉。
- **纵深递进，不是并列。** 第 N+1 个场景必须比第 N 个更静、更暗、更慢、更少信息。
  五个一样热闹的场景等于没有推进。
- **身体放松可以分轮。** 长版（30 分钟以上）把身体放松拆到 2–3 个场景里分批完成，
  而不是开头一次扫完再也不提。
- **允许留白句配额。** 每个场景末尾留 1–2 句几乎不携带信息的空句，这是长版最合法的
  "时长来源"，也是听者掉线的入口。
- **禁止**：同义句复述、形容词堆砌、把一个画面用三种说法说三遍、为凑字数插入与主意象无关的段落。
- **禁止**：为了缩短而删掉呼吸轮次、身体放松或入睡落地。短版是**减场景**，不是减要素。
- 各分册怎么花这份预算不同（例如 B 册不串联五个场景，而是在同一诗境里加深留白），
  以分册规定为准。

### 6. 参数

调用时确定以下参数，未指定用【默认】。

- `book` 分册：A–F。未指定时按 §1.3 路由自动判定。【默认：按路由】
- `theme` 主意象/母题：由用户主题或选题器给出。【本流水线：始终由上游选题步骤给出】
- `mode` 版式：`full` / `scene`（场景纯享）/ `accept`（接受式），见 §5A。【默认：full】
- `duration` **成品**时长：10 / 15 / 20 / 30 / 45 / 60 / 90 分钟，或 `natural`
  （不设分钟目标，按 §5.5 落到 20 分钟档）。【默认：natural】
- `speech_minutes` **人声段**时长：由 `duration` 按 §5B 表推出，**上限 30**。
  ≤30 分钟时等于 `duration`；>30 分钟时固定为 30，差额由白噪音补。写稿只看这一个数。
- `ambience` 接续的白噪音：雨 / 溪流 / 海浪 / 火 / 风 / 虫鸣 等，必须与主声音同源（§5B.1）。
  `speech_minutes < duration` 时**必填**。【默认：由主声音推出】
- `mechanism` 入睡机制的**结构变体**：`linear`（默认，分册原有中段手法）/ `loop`（无叙事循环）
  / `single`（单通道），见 §6B.2。**注意 §6B.1 的三条曲线是全篇必备，不受此参数影响。**
- `pipeline` 配音管线：`extreme`（极限滞后，已校准）/ `v3` / `base`。【默认：extreme】
- `wake` 是否带唤醒：`true` 用于午休 NSDR，结尾必须执行 §4.5；`false` 夜间，
  结尾严禁任何唤醒内容。【默认：false】
- `audience` 受众：`adult` / `child`。【默认：adult】
- `title` 是否输出标题。【默认：false，仅输出正文】

句子更短、更多拟声；呼吸叫"魔法呼吸"；全程强调"你是安全的，被爱着的"；
意象温暖奇幻绝对安全；§4 安全规则全部适用且标准更严。

### 6B. 入睡机制（第二维度）

### 6A. 通用技法库（六册共用，按需取用）

这些是语料里反复出现的处理手法，**不属于任何分册**，六册都可以用。

### 6A.1 负面情绪四步：看见 → 不评判 → 感谢 → 放下

处理放松或漫游中"看见"的紧张、焦虑、杂念。四步固定顺序，不可跳步。

> 也许这里，还藏着一点点着急。没有关系。
> 你可以试着，轻轻的对它说一声谢谢。
> 我知道，你只是想让我今晚睡好。我不怪你。
> 好。我们继续往下。

要点：

- **情绪永远是"好意的信使"，不是敌人。** 不对抗、不驱赶、不分析原因。
- **感谢之后立刻移开注意力**，不停留、不追问、不展开成故事。
- 每篇至多用一次。用多了会变成"检查自己有多少问题"，那会激活。

### 6A.2 念头外化（处理"脑子停不下来"）

把念头写成**可以自己飘走的东西**，不追随、也不驱赶。

> 如果有念头飘过来，也没有关系。就像远处的云。飘来。又飘走。
> 不追。也不赶。你只是躺在这里。看着它们，经过。

要点：外化物必须**会自己走**（云、水面的落叶、窗外的车灯、飘过的雪），
不能是需要处理的东西（不能写"把念头放进盒子里"——那是一个任务）。

### 6A.3 悖论意图（失眠焦虑首选，`accept` 版必用）

**明确告诉听者不必睡着。** 卸掉"必须入睡"的压力，压力本身就是失眠的主因。

> 今晚，我们不强求睡着。也不拒绝清醒。
> 允许自己醒着。也允许自己睡着。
> 就算今天没有睡好，你依然是被接纳的。
> 你不是一个有问题的人。你只是此刻还醒着。

要点：

- 只出现在**开场与中段**，**绝不出现在结尾**——结尾必须按分册手法收在入睡（§4.4）。
- 不得写成条件句（"只要你不强求，就能睡着"）——那又变成了要求。

### 6A.4 安全锚

全篇反复给出"被托住、被支撑、被守护"的意象，这是整套风格的安全感底色，
也是语料里最高频的技法（"托住"出现 52 次、"融为一体"21 次）。

每篇至少三处，写法随分册的载体走：床垫托着你、云托着你、大地接住你、
被子压着你、椅背稳稳靠着你、水面把你浮起来。

### 9. 交付格式

除非用户另有要求，**只输出文稿正文**：一段连续、可直接朗读的中文文本，
按句号断句、自然分段，不含标题、编号、括注或写作说明。

`title=true` 时加标题，按 `mode` 取前缀：
`full` / `accept` → `【催眠入睡】标题`；`scene` → `【场景纯享】标题`；

同一主题同时要 `full` 和 `scene` 两版时，**先写 full，再由 full 剪出 scene**
（按 §5A.1 删头部、把放松嵌进场景），不要各写一遍——语料里两版的结尾几乎逐字相同，
就是这么来的。

**接白噪音的篇目**，在正文之后另起一行注明（这一行不参与配音）：

```
［接续］白噪音：<声音名>　人声段：<N> 分钟　成品：<M> 分钟　自第 <N> 分钟起淡入
```

出平台文案时交给 `sleep-content-publisher-copywriter`；选题由 `sleep-topic-picker` 提供。
