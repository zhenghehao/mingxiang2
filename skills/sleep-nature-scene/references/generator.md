# 自然梦境五轴生成器

没有完整主题或需要把抽象需求转成场景时读取。每轴选择一项，组合必须自洽，并避开最近五篇使用过的轴值。

| 轴 | 候选 |
|---|---|
| 入口 | 林间小路、木栈道、草坡、青苔石阶、干河床、沙滩、半开木门、老巷、麦田小径、湿地浮桥、竹林边、果园篱门 |
| 介质 | 薄雾、细雨、落叶、齐膝草、脚踝浅水、新雪、花瓣、苔、软沙、温泉水汽、竹影、芦苇、暖风 |
| 最深处 | 静水边平石、炉火小屋、开阔草地、洞中温泉、大树下、湖心浮台、空亭、松针地、背风凹处、谷底暖沙 |
| 主声音 | 雨、溪流、风穿叶、海浪、火的轻响、虫鸣、洞顶水滴、芦苇摩擦 |
| 时辰 | 傍晚、深夜、雨刚停、起雾凌晨、圆月夜、雪停后、秋末、夏夜、冬日斜光、将亮未亮 |

优先避开云、雨林、湖、海浪和萤火等高频组合。最深处必须能稳定停留；封闭空间必须有光；主声音必须全程同一个。抽象需求只提供情绪方向，不把抽象词直接写进正文。
