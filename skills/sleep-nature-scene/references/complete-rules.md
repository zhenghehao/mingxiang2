# 当前 Skill 内置的完整通用规则

本文件属于当前 Skill 自己，不是共享文件、父 Skill 或对子 Skill 的调用。每个助眠 Skill 都各自包含一份独立副本，单独复制当前目录即可使用。

本文件补充主 `SKILL.md` 中为保持轻量而省略的高级能力。主文件的题材专属开场、中段和结尾始终优先；本文件只能补充通用机制，不能把六册写成同一种结构。

## 参数与读取条件

支持以下完整参数：

- `duration`：10、15、20、30、45、60、90 或 `natural`。`natural` 按 20 分钟人声档处理。
- `mode`：`full`、`scene`、`accept`。
- `mechanism`：`linear`、`loop`、`single`。默认 `linear`。
- `pipeline`：`extreme`、`v3`、`base`。默认 `extreme`。
- `wake`：夜间 `false`，午休/NSDR `true`。
- `audience`：`adult` 或 `child`。
- `title`：是否输出标题。
- `ambience`：30 分钟以上成品接续的同源白噪音。

遇到以下任一情况时完整读取本文件：

- `mode=accept`
- `mechanism=loop` 或 `mechanism=single`
- `pipeline` 不是 `extreme`
- `duration` 为 45 分钟以上
- 用户要求严格质检、完整母规则、机制变化或配音校准

普通 10–30 分钟、`full/scene + linear + extreme` 请求，以主 `SKILL.md` 为主，不必加载本文件。

## 规则优先级

按以下顺序处理冲突：

1. 夜间/午休结尾铁律与安全禁令。
2. 当前 Skill 的专属开场、中段、身体放松和结尾。
3. 本文件的长度、机制、曲线、语言和质检规则。
4. 用户偏好与自由创意。

`mechanism` 只改变中段形状，不得替换当前分册的开场和结尾。`mode` 只改变篇幅分配，不得删除呼吸、身体放松、意象和落地功能。

## 长度、管线与预算

### 极慢沉浸管线

`pipeline=extreme` 已校准：约 49 个可朗读中文字/分钟，不统计标点、空白与 TTS 标签。

| 人声时长 | 目标字数 |
|---:|---:|
| 10 分钟 | 520–550 |
| 15 分钟 | 750–810 |
| 20 分钟 | 1000–1050 |
| 30 分钟 | 1450–1560 |

`natural` 使用 20 分钟档，可在目标区间外浮动约 15%，但不得低于 520 字。

人声上限为 30 分钟。45、60、90 分钟成品分别使用 30 分钟人声加 15、30、60 分钟白噪音。

### 其他管线

`v3` 与 `base` 没有可靠通用字数常数。用户没有提供实听锚点时，按 `extreme` 字数写，并明确标记“字数按 extreme 校准，实际时长需试音”。不要凭感觉编造另一管线的字数。

需要校准时，取一篇已完成音频，记录播放到第 10 分钟和第 20 分钟时读到的位置，分别统计此前可朗读中文字数。用至少两个节点估算该管线的字/分钟；音色、语速或停顿密度改变后重新校准。

### 每结构单位预算

动笔前计算：

`每单位字数 =（目标总字数 − 开场预算 − 结尾预算）÷ 结构单位数`

写完一个单位立即核对，不要全文结束后靠形容词补字。

合法扩写按优先顺序使用：

1. 在同一感官通道内增加一层细微差异。
2. 把一个身体部位的松开拆成两个连续瞬间。
3. 多写一轮自然呼吸，每轮落在不同触感。
4. 让主声音或温度产生一次很小的变化。
5. 回到已经出现的物或层次，但第二次更短、更淡。
6. 增加低信息空句，不增加新物象和新事件。

禁止用同义句堆叠、形容词串联、额外故事或无关场景凑字。留白会减少文字，不能单独承担补字任务。

## 三条入睡曲线

三条曲线在所有册、所有机制下都执行；`wake=true` 时只走到全文约三分之二，随后为唤醒段恢复完整句法和称呼。

### 波浪下沉

安排三次下沉和两次微浮：

`下沉一 → 微浮一 → 下沉二 → 微浮二 → 下沉三到底`

微浮只写一个远处声音、掠过的念头或刚被注意到的身体小动作，每次 15–30 字且不超过两句。立即说明没有关系，让它自行过去；不判断、不处理、不在后文回收。最后一次下沉后不再浮起。

### 句法解体

让语言按四级逐渐失去完整语法：

| 级别 | 形态 | 使用位置 |
|---|---|---|
| L1 | 完整主谓句 | 开场约 80% |
| L2 | 省略主语 | 中段前半 |
| L3 | 名词、形容词或位置短语 | 中段后半 |
| L4 | 1–2 字或气音 | 结尾 |

开场不要从碎句起步；结尾不要仍以完整主谓句为主。句法先解体，句长会自然递减。

### 去称呼

- 开场：“你”约每 40–60 字出现一次。
- 中段：“你”约每 100–150 字出现一次。
- 最后约 200 字：“你”出现 0 次。

后段把动作交给肩膀、手、呼吸、物象和声音本身。去掉称呼不等于改讲第三人称；任何位置都不要引入“他/她”作为新的叙述主体，除非当前分册明确允许的开场或背景角色。

## 三种结构机制

### `linear`

执行当前 Skill 主文件规定的专属中段结构。默认使用。

### `loop`

让中段后半进入无叙事循环：

- 选择 3–4 个来自当前母题的短句作为轮转组。
- 每轮只改 1–3 个字，不增加新信息，不做变奏解释。
- 逐轮更短、更慢、更碎，按 L2 → L3 → L4 下沉。
- 不超过 4 句，避免形成记忆任务。
- 30 分钟档优先采用“前 2/3 专属 linear + 后 1/3 loop”。

E 册的锚句回环仍是其专属结构：锚句与意象段交替。通用 `loop` 是整个中段后半没有推进，不要混为一谈。

### `single`

整篇只使用一个感官通道：触觉、听觉或温度。禁止以视觉作为唯一通道。

同一通道仍需有层次：

- 触觉：重量 → 温度 → 质地 → 接触面积 → 边界变模糊。
- 听觉：远近 → 清钝 → 回声 → 与呼吸合并 → 只剩底声。
- 温度：表面 → 肌肉 → 被包裹范围 → 均匀 → 不再分辨边界。

`single` 适合 `accept`、`scene` 和容易被画面激活的听者。

## 三种版式

### `full`

执行当前 Skill 的完整开场、中段和结尾，字数按目标档。

### `scene`

使用同档 `full` 字数的 60%–70%。按当前 Skill 指定的场景入口删去显式引导头部，身体放松嵌进画面，呼吸变成环境节律。不得删除专属结尾和夜间/午休铁律。

若用户要求 `scene` 版也达到某个完整播放时长，应提高写作档位，而不是仍按 60%–70% 后声称时长不变。

### `accept`

字数与 `full` 相同，减少约一半意象单位，把腾出的篇幅用于允许和觉察：

- 明确不强求睡着，也不拒绝清醒。
- 许可表达至少 8 处，分散出现。
- 必须使用一次“负面情绪四步”。
- 可配 `mechanism=single` 收窄感官。
- 悖论意图只出现在开场和中段，结尾仍按当前 Skill 收向入睡。

## 通用处理技法

### 负面情绪四步

每篇至多一次，顺序不可变：

1. 看见一点紧张、着急或杂念。
2. 不评判，不分析原因。
3. 感谢它原本想保护自己或帮助今晚休息。
4. 让注意力离开，回到当前物象、声音或身体触感。

不要把情绪写成敌人，也不要停留检查更多问题。

### 念头外化

让念头像云、远光或水面叶片一样自己经过。不追、不赶、不放进盒子、不要求听者处理。外化物必须能自行离开，不留下任务。

### 悖论意图

明确允许醒着、允许没有立刻睡着。不得写成“只要不强求，就一定能睡”，否则仍是条件和任务。夜间结尾不再提“醒着”，避免重新激活。

### 安全锚与许可

普通版至少 3 处许可表达、至少 3 处被托住或被支撑的安全锚；`accept` 至少 8 处许可。分散到全文，不连续罗列。

## 语言、节奏与安全

- 开场以 10–14 字自然完整句为主；中段逐步变短；结尾以 1–6 字为主。
- 单句不超过 25 字，一句只承载一个动作或意象。
- 每个自然段至少有一个软化词：轻轻、慢慢、缓缓、静静、微微或渐渐。不要机械重复同一个。
- 每 150–200 字至多引入一个新比喻；一句不套两个比喻。
- 使用口语连接词，避免“因此、然而、综上、首先、值得注意”等论说语。
- 以描述、邀请和许可代替命令。禁止“你应该、你必须、请想象、请随我”。
- 不作医疗诊断、治疗承诺、科学背书、依赖暗示、商业植入和下期预告。
- 不制造悬念、任务、时间压力、比较、竞争和需要理解的抽象论证。
- 禁止死亡、尸体、深渊、窒息、溺水、失重、被困、追赶、威胁、噩梦、黑暗吞噬等表达。
- 疲惫、紧张、焦虑、睡不着只能描述性带过，不渲染、不病理化。
- 所有向下移动都被稳定载体承接；夜色只温柔包裹；水只承托，不淹没。
- 禁止突然、猛地、迅速、快点、马上、赶紧等刺激与时间压力。

### 夜间/午休铁律

`wake=false`：结尾不得出现睁眼、活动身体、恢复活力、清醒、元气或明天任务，只能渐弱入梦。

`wake=true`：按顺序完成：

1. 让画面和光线逐级变亮。
2. 自然加深一次呼吸，呼气保留平静。
3. 先活动手指、脚趾，再转动手腕、脚踝。
4. 舒展双腿、双臂和肩颈。
5. 完全苏醒后再慢慢睁眼。
6. 以清爽、从容或元气结束，不写晚安、好梦或继续入睡。

## 白噪音接续

30 分钟以上成品必须满足：

- 主声音和接续白噪音同源。
- 优先雨、溪流、海浪、火、风穿叶或稳定虫鸣。
- 不使用雪落（无声）、钟声与风铃（周期易被数）、鸟鸣（变化易唤起）作为长时间接续主声。
- 若题材原声不适合，至少在交接前约 3 分钟自然引入一个可持续声音。
- 专属结尾完成后再写 80–120 字交接段；交接段不得替代专属结尾。
- 句子逐步退到词，声音逐步升为唯一还在的东西。
- 落款若使用，应为最后一句人声；之后不再出现人声。
- 正文后注明声音名、人声时长、成品时长和淡入时间。

## 防趋同与轮换

六册专属动作不可互换：

| Skill | 开场 | 中段 | 结尾 | 身体放松 |
|---|---|---|---|---|
| 道禅 | 减法陈述 | 四拍双螺旋 | 格言消融 | 每圈分批对齐 |
| 古诗文 | 准确原句 | 诗眼四折、感官换层 | 回到原句 | 整体下沉 |
| 童话 | 第三人称滑门 | 单角落停留 | 他人合书 | 外物从下向上覆盖 |
| 动漫影视 | 无人称声音 | 被载着、窗外流过 | 夜间不到站 | 随外部均匀节律 |
| 华语歌曲 | 熟悉感脱敏 | 自撰锚句回环 | 尾音渐弱 | 随语言回环 |
| 自然场景 | 天气陈述 | 多场景纵深路线 | 交给主声音 | 分场景完成 |

连续生成时维护最近 5 篇简表，至少记录：主题或轴值、开场变体、身体放松载体、结尾变体、主声音。新稿任一关键轴与最近一篇相同就优先更换；同族主题、同一结尾连续出现不得超过一次。

## 交付与量化检查

默认只输出连续正文，不输出标题、编号、括注、写作说明和 TTS 停顿标签。

`title=true` 时：

- `full` / `accept`：`【催眠入睡】标题`
- `scene`：`【场景纯享】标题`
- 儿童版：`【催眠入睡】儿童睡前解压放松—副标题`

若同时交付 `full` 与 `scene`，先写 `full`，再从中剪出 `scene`，保持专属结尾一致。

生成草稿后运行 `scripts/check_draft.py`。脚本只检查字数、句长、禁用词、许可数量、软化词、去称呼和结尾唤醒风险；题材专属结构仍按主 `SKILL.md` 人工复核。
