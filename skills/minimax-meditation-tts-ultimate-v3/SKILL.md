# MiniMax 深度沉浸助眠配音文本优化 3.0

把现有冥想文稿加工成 MiniMax `text` 字段可以直接合成的纯文本。要求极致还原“极慢、极轻柔、极具催眠感”的说话方式。不要改写核心含义，不处理背景音乐，不处理音色克隆或文件上传。

## 核心语感与节奏切分（六大高阶心法）

1. **意群极度碎化（物理放松感）**：打破常规长句，按“意群”甚至“词组”切分。用高频短停顿营造极致慵懒、说话仿佛“半词半句拖拽”的微醺感。
   - 示例：`想象，<#0.8#>此刻的你，<#1.0#>正安安静静地，<#1.2#>躺在草地上。`
2. **钟摆对称与自然同频（被动节律感）**：遇到“一进，一出”、“一层，一层”等极简对称词，强制使用绝对相等的长停顿（如 `<#2.5#>`）。遇到“海浪退去”、“水波荡漾”等自然意象，用长留白契合大自然的物理周期。
3. **心理卸防与顿悟共鸣（深层疗愈感）**：遇到“没关系”、“不需要管”、“允许自己”等卸防词，或“宇宙能量”、“生命本质”、“温柔同行”等打破孤独的顿悟/抽象词，必须在其后加入长停顿（`2.0-3.0` 秒），给听众大脑留下品味、震荡与释然的空间。
4. **口语随性与意识游离（意识解离感）**：遇到“嗨、呀、那么、挺舒服的”等极度日常口语时，加入微停顿（`0.5-0.8`秒）消除朗读腔。当文本暗示“听不清也没关系”、“不用管它”时，将句间停顿拉长至 `4.0-6.0` 秒，模拟声音渐渐飘远、意识断联的失重感。
5. **张弛反差与阶梯蓄力（动态旅程感）**：描述“疲惫攀爬/挣扎”时用沉稳的匀速停顿，紧接着“坐下/解脱”瞬间必须给出一个反差极大的超长留白（`4.0-5.0` 秒），制造彻底卸下重担的解脱感。描述“生命发芽/力量汇聚”时，停顿应呈阶梯式递增（如 `<#1.0#>...<#2.0#>...<#4.0#>`）。
6. **环境音接管与终极消散（声音退场感）**：当提示“去听雨声/只管躺着什么都不做”时，主动留出 `4.0-5.0` 秒停顿，把舞台完全让给白噪音。结尾的告别句必须切得极碎，呈现阶梯式长尾消散，模拟卸去最后力气的虚弱与沉睡。
   - 示例：`就这样。<#3.0#>慢慢，<#2.0#>睡去。<#4.0#>晚安。<#8.0#>`

## 停顿标记规范 `<#x#>`

在句内与句间必须高频且精准地加入合法停顿标记：
- **口语微顿 / 碎化意群（营造句内拖拽与真实感）**：`0.5–1.2` 秒；
- **沉重步伐 / 普通安抚描述（普通句间）**：`1.5–2.5` 秒；
- **被动自然呼吸 / 精神词汇共鸣 / 同频顿悟留白**：`2.0–3.0` 秒；
- **心理脆弱抚慰 / 彻底卸下重担的极致反差留白**：`3.0–4.0` 秒；
- **主动深呼吸 / 环境音主动接管 / 意识断联游离**：`4.0–6.0` 秒；
- **入睡终极结尾（声音渐弱至彻底消失）**：极碎化词组配合阶梯长留白，最终达到 `<#8.0#>` 或更高。

## 其他处理流程

1. 保持原稿的开场、身体扫描、想象旅程、深化、结尾的整体结构不变。
2. 呼吸引导只能写听众应该直接听见的中文，绝对禁止直接照搬外文动作提示。
3. 保持中午或晚上的结尾要求：中午保留完整唤醒语，晚上则禁止加入唤醒，让声音自然消散淡出。

## 强制约束检查（必须严格遵守）

- 禁止输出 `(inhale)`、`(exhale)`、`(breath)`、`(sigh)`、`(humming)` 等英文括号动作标签，它们会被当作正文读出。必须转化为自然中文：`轻轻吸气`、`缓缓呼气`、`轻声叹息`等。
- `<#x#>` 的 x 范围为 `0.01–99.99`，最多两位小数。
- **绝对禁止连续放置两个停顿标记（如 `<#1.0#><#2.0#>` 是严重错误）**。每个 `<#x#>` 前后都必须有可发音的中文字符或中文标点。
- 不输出舞台说明、JSON、curl、Markdown 代码围栏或预计时长等与合成配音无关的文本。
- 单次处理文本必须少于 10000 字。严格只输出包含 `<#x#>` 标记的纯文本。
