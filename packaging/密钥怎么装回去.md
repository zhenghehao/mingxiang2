# 密钥怎么装回新机器

这个目录里是你**本人的**全部密钥，明文。装完建议把这个目录删掉，
别让它一直躺在新机器的桌面上。

## 1. 三把主程序钥匙（进钥匙串）

在新机器上打开终端，逐条执行（`$(cat …)` 是为了别把密钥打进命令历史）：

```bash
cd 到这个"密钥-不要外传"目录

security add-generic-password -U \
  -s com.shareit.sleepflow-studio -a minimax-subscription-key \
  -w "$(cat minimax-subscription-key.txt)"

security add-generic-password -U \
  -s com.shareit.sleepflow-studio -a minimax-api-key \
  -w "$(cat minimax-api-key.txt)"

security add-generic-password -U \
  -s com.shareit.sleepflow-studio -a text-provider-api-key \
  -w "$(cat text-provider-api-key.txt)"
```

装完在 4319 界面的「API 设置」里点一下检测，能读到账号就对了。

也可以不敲命令：直接在界面的「API 设置」里把 `.txt` 里的内容粘进去，
效果一样（程序自己会写钥匙串）。

## 2. Codex CLI 登录态

只有在「文本引擎」选 codex-cli 时才需要。走 API 模式可以跳过。

```bash
mkdir -p ~/.codex
cp auth.json config.toml ~/.codex/
chmod 600 ~/.codex/auth.json
```

## 3. 商汤 SenseNova（画 B 站封面）

这把 key 直接写在 `冥想一键工作流/src/cover.mjs` 里，跟着包走了，
新机器上不用做任何事。想换成环境变量的话：

```bash
echo 'export SENSENOVA_API_KEY="……"' >> ~/.zshrc
```

代码是 `process.env.SENSENOVA_API_KEY || "写死的那个"`，环境变量优先。

## 4. Agnes 的模型密钥

内联在 `agnes-playground/agnes-playground.html` 里，跟着包走了，
打开页面就能用，不用重填。

## 5. 平台登录态（没能打包，要重新扫码）

发布是用 CDP 连你真实的 Chrome，所以七个平台的会话存在 **Chrome 的用户资料**
里，不在发布器目录里 —— `最终发布/.publisher_data/cookies/` 是空的，
那儿只有任务记录。这部分没法跟着 zip 走。

新机器上用调试端口启动 Chrome，然后各平台重新扫一次码：

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222
```

在 4319 界面「发布到各平台 → 查看发布状态」里能看到哪个平台掉线了。
