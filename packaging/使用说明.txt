冥想一键工作流2 · Intel Mac 完整迁移包

适用电脑
  Intel x86_64 Mac，macOS 12 或更新版本。
  只需已安装 Google Chrome 并能正常联网，不需要另装 Node、Python、FFmpeg。

安装
  1. 解压“冥想一键工作流2-Intel-完整迁移包-含API.zip”。
  2. 按住 Control 点击“安装冥想一键工作流2.command”，选择“打开”。
  3. 安装器会把应用放到：
       ~/Applications/眠屿工作台.app
  4. API 密钥会导入当前用户的 macOS 钥匙串；包内 credentials 原始副本不会删除。
  5. 安装完成后会自动启动，并打开 http://127.0.0.1:4319。

第一次使用
  1. 顶部“平台草稿”显示绿点，说明内嵌草稿服务正常。
  2. 打开“平台草稿”，逐个平台查看登录状态。
  3. 登录失效的平台点“打开登录”，正常扫码或完成平台验证。
  4. Cookie 只能尽力迁移；B站、喜马拉雅、网易云在新 Mac 首次使用时通常要重新登录。
  5. 平台验证必须由本人完成，系统不会绕过验证码或风控。

日常流程
  1. 在主界面生成冥想工作流。
  2. 完成后系统自动打开七平台草稿窗口。
  3. 检查最终视频、音频、4:3/16:9 封面和七套文案。
  4. 勾选平台后，手动点击“存入草稿箱 / 准备人工确认”。
  5. 抖音、快手、小红书、视频号、B站只保存草稿。
  6. 喜马拉雅、网易云只上传并填表，停在最终人工确认前。
  7. 最后由你进入各平台人工检查并发布。

B站
  系统填写简介、标签、双封面、AI 声明和“健康”分区。B站草稿不持久化新版
  “健康”字段，因此系统保存后会重新打开草稿并预选“健康”，把编辑页留给你。

重要安全说明
  本 ZIP 含 API 密钥、Codex 登录配置、蚁小二配置和平台 Cookie，等同于账号资料。
  只在你自己的电脑之间传输，不要上传公共网盘、GitHub 或发送给他人。
  程序没有自动正式发布入口，也不会自动点击“发布”“确认发布”或“提交”。
